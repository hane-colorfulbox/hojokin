# 補助金業務ガイド

## 第7次以降の適用（2026-11-04）

[変更点と使い方](docs/第7次申請_変更点と使い方.md) と [確認待ち事項](docs/第7次申請_確認待ち事項.md)、[公式資料で判断できることと確認の範囲](docs/第7次申請_公式資料で判断できることと確認の範囲.md) を先に確認する。給与0年度目は見込み値（窓口担当の事務局照会回答をユーザーが提示済み）。給与の当期見込みと生産性の前事業年度実績を分け、過去交付歴・表明・対象人数・根拠の未確認をAIで埋めない。効果報告の比較基準は未確定で、今回は申請向け対応まで。

通常枠の申請書確定には、生産性の前事業年度実績と、計画1年度目＝申請翌事業年度から3年度目＝申請3期後までの確認済み計画（営業利益・人件費・減価償却費・総労働時間・根拠・確認状態）も必要。給与0年度目見込みと分け、150万円未満・任意賃上げなしでも省略しない。初年度と3年平均の3%／過去指定枠交付あり4%を検算し、旧原本B42のOK表示だけを根拠にしない。未確認なら該当申請書の提出用確定出力を止めるが、原本転記・実績集計・不足事項の整理は進めてよい。

生産性の基準（0年度目）は前事業年度実績、給与0年度目は申請当年度見込み。計画1〜3年度目は両指標とも申請翌事業年度・翌々事業年度・3期後で同じ期間となる。違うのは基準年度であり、計画1年度目を申請当年度にしない。

第7次以降の全4原本では、給与0〜3年度目の計画入力が必要。賃上げ率の達成義務・表明義務・任意加点の有無と、入力が必要なことは別である。通常枠は公式FAQ No.39、インボイス等は申請マニュアルp.89・91の入力指示に基づく。回収票・ヒアリングの最終形は社内運用調整であり、一般ルールの事務局再照会を前提にしない。

以下の加点条件は第7次以降用。第1〜6次の訂正・再出力には旧版を使い、公募回・実申請月・原本版を明示する。過去の検証日・会議発言・実装経緯は当時の記録であり、新要件の裏取りとして流用しない。

## 2. いつも守るルール

1. 答える前に、上の振り分けで該当する資料を読む。資料に書いていないことは「資料に書いていない」と言い、推測で埋めない。
2. 制度の数値（R215/R216 の定義、最低賃金+55円、暦月固定など）は1文字違うと申請が狂う。02 と、必要なら 02 末尾の公募要領（一次資料）で裏を取る。
3. 🔴 案件を扱う前に「申請枠」と「法人／個人事業主」の2つを必ず確定する。当社が扱うのは 通常枠×法人 / 通常枠×個人事業主 / インボイス枠×法人 / インボイス枠×個人事業主 の4通りで、申請書テンプレもヒアリング様式も4通りそれぞれ別物。枠だけで決めると、法人用テンプレで個人事業主の申請書を作る事故になる（役員欄・資本金・決算月・計画年度が全部食い違い、しかも空欄の数には出ない）。対応表は [docs/弊社成果物と書式.md](docs/弊社成果物と書式.md) §3。
4. 通常枠も個人事業主が申請できる。古い資料の「通常枠は法人のみ」は誤り。個人事業主には履歴事項全部証明書が無く、決算書は所得税の青色申告決算書（白色なら収支内訳書）。
5. 実績台帳の月列は指定した実績事業年度の12か月（暦年固定ではない）。給与0年度目の当期見込みは確認済みの総額・FTE・根拠を別入力し、実績を自動流用しない。反対に、加点判定用の台帳は暦月固定（令和7年10月〜令和8年9月＋交付申請直近月）。取り違えやすいので毎回確かめる。
6. 給与指標は各算出対象年度の全月支給者を対象とし、途中入退社で全月支給がない年度だけ除外する。パート等は正社員の就業時間に換算し、所定の福利厚生等による時短勤務者は除外可。通常の役員除外と従業員ゼロ法人の役員読み替えを区別する。一般定義は公式確認済みなので再照会せず、未回収・0円・非在籍など個別の事実不足だけ確認する。
7. 新規申請の見込み給与は、公式の課税給与定義で確認する。通常の課税手当は算入。課税通勤も一般定義から算入する解釈で、個別回答済みとは表現しない。通勤全額控除の既存社内方式との不一致を「公式不明」とは扱わず、旧方式・旧成果物は無断修正しない。旧実績台帳のS列方式は04の落とし穴(3)を参照し、新規見込みへの自動流用をしない。
8. 賃上げ計画は1人当たりで1年後・年平均を検査。通常枠150万円境界・過去交付・任意加点・適用除外から必要な3%／3.5%を分岐する。交付歴の一律なし・表明の一律はいを禁止し、未確認値の提出用確定を止める。
9. 加点判定は、標準の賃金台帳ではなく専用の加点判定用台帳で行う（katen-judge スキル）。判定エンジン（katen-judge スキル内の `hojokin/`）はツール本番と同じコードなので編集しない。
10. ★グレーの過去記録は現行の公式資料と照合する。公式資料で判断できる一般論は再照会せず、明文を当てはめきれない具体例や必要な事実だけを窓口担当へ渡す。効果報告の比較基準は今回は保留し、同じ質問を繰り返さない。
