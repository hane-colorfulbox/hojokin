# 07 ツールとローカルの役割分担

「ツール（Streamlit Cloud の書類作成ツール）」と「ローカル（手元の Claude Code ＋パック同梱スキル）」のどちらで何をやるかの総覧です。迷ったらこの1枚を見てください（2026-07-21 の3次申請振り返りで確定した体制）。

## 基本の考え方

- **ツールとローカルの情報・出力規格は常に一致させる**。同じテンプレ列・同じ補助金ルール（R215/R216・加点の定義）で動く。規格を変えたら必ず両方を同期する（正本ルール: `補助金/CLAUDE.md`「賃金台帳の回収方針」）。
- **ツールは「速い・簡単・誰でも」**。ブラウザだけで動き、定型の書類生成が得意。ただし複雑な判断・大規模な処理・PDF の丁寧な読み取りはできない。
- **ローカルは「複雑・大規模・高精度」**。最も精度の高いモデルで PDF を読み、検算・感度チェックまで含めた丁寧な作業ができる。手書き・画像 PDF や、100名超の台帳、判断の割れる案件はローカルでやる。

## タスク×経路の総覧

| タスク | 標準経路 | もう一方の扱い |
|---|---|---|
| 申請書の作成（通常枠・インボイス枠） | **ツール**（「申請書作成」タスク） | ローカルでは作らない（ツールが正） |
| R215/R216 の算定・検証 | **ツール**（「一人当たり給与支給総額」タスク） | ローカルは入力 Excel の作成側を担当 |
| 賃金台帳 PDF → 規格 Excel 変換 | **ローカル**（`wagebook-convert` スキル。標準・精度優先。出力に原本転記シート群＝PDF全ページ・全項目の転記付き） | ツール「賃金台帳の作成」は速さ優先・CC 環境が無い/不慣れな人向けの代替（原本転記シートは付かない。転記が要る案件はローカルへ） |
| 加点判定（賃上げ加点①②・補助率2/3） | **ローカル**（`katen-judge` スキル。PDF台帳→専用台帳→判定→公式様式①②まで完結） | ツールの「加点判定用賃金台帳の作成」「加点判定」タスクは Excel 入力用（PDF 未対応） |
| 案件フォルダの必要書類チェック | **ローカル**（`case-docs-check` スキル。Drive 読み取り専用） | ツールに同等機能なし |
| セカンドオピニオン加点の面談準備 | **ローカル/チャット**（プロンプト2本立て: 07B 確認メール → 06 予約フォーム入力文。07・06B は使わない） | ツールに同等機能なし |
| 台帳を出したくない顧客の総額提出 | 顧客が**総額提出用テンプレ**（`ツール/賃金台帳（総額提出用）テンプレート.xlsx`）に自己記入 | 記入結果の検算はローカル・ツールどちらでも可 |

## ローカル側の同梱物（このパックに入っているもの）

- スキル3本：`.claude/skills/wagebook-convert/`（台帳変換）・`.claude/skills/case-docs-check/`（書類チェック）・`.claude/skills/katen-judge/`（加点判定）
- 判定エンジン：`hojokin/`（ツール本番と**同一のコード**。パックのビルド毎にリポジトリからコピーされるため、ローカルとツールで判定結果がズレない。**このフォルダは編集しない**）
- テンプレ・公式様式：`ツール/加点判定用賃金台帳テンプレート.xlsx`、`補助金加点/`（加点の公式様式3枚）
- チェックリスト：`docs/チェックリスト_加点判定.md`（加点判定の実行手順の正本）
- 実行環境：Python 3.10+ ＋ openpyxl だけで動く（pandas 等は不要）

## 出力規格の同期ルール（ズレると事故になる約束事）

1. **賃金台帳テンプレの列・補助金ルールを変えたら、ツールとスキルの両方を直す**（過去例: T列「年間賞与」追加時は両テンプレ＋配布 ZIP を同期）。
2. **原本転記シートの名前規約**：スキル出力の PDF 丸ごと転記シート群（表紙＋ページ別 `原本転記_pN`）は、シート名を「原本転記」で始める。ツールのリーダーはこの名前の可視シートを全経路で読み飛ばす（v0.2.91〜）。**どちらか片方だけ変えてはいけない**（リネームするとツールが表として誤読し R215/R216 を壊す）。転記の中身は**全ページ・全項目**が規格（集計行だけの転記は不可。2026-07-26〜）。
3. **加点判定用テンプレを変えたら両系統を同期**（考え方は標準台帳と同じ）。
4. 賃上げ計画値は**常に切り上げ**（2026-07-21 決定。四捨五入だとポータルの伸び率が 2.9% 表示になる1円事故があるため）。

## 全員のローカル環境（2026-07-21 決定）

チーム全員が引き継ぎパック（hojokin-handoff.zip）＋同梱スキルを自分の PC にインストールする（各々実施・詰まったらミーティングで補助）。導入手順はパック直下の `CLAUDE.md`（配布版）の「使い始め」を参照。
