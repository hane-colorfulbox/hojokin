# 01 補助金とは・業務の全体像

この補助金業務は、中小企業のITツール導入を国が支援する「デジタル化・AI導入補助金（旧IT導入補助金）2026」について、申請企業に代わって申請書類を作成・支援する仕事です。我々（支援する側）は、顧客から集めた資料をもとに、AIを使って申請書類を半自動で作り上げています。このページでは「そもそもこの補助金は何か」「案件が入ってから書類を出すまで何が起きるか」「どんな道具を使うか」を、全体像として押さえます。個別の制度ルールやツールの操作は、それぞれの専用ページにリンクしてあります。

---

## 1. この補助金は何か

- 正式名称: **デジタル化・AI導入補助金（旧IT導入補助金）2026**
- 内容: 中小企業のITツール導入を支援する国の補助金。
- 申請枠は次の3種類があります。

| 申請枠 | 対象 |
|--------|------|
| 通常枠 | 法人 |
| インボイス対応類型 | 法人 |
| インボイス対応類型 | 個人事業主 |

### 我々が代行していること

我々（支援する側）が担っているのは、**申請書類の作成です**。顧客から集めたヒアリングシート・登記簿（履歴事項全部証明書）・決算書（損益計算書）・賃金台帳などをもとに、AI（Claude API）が書類の内容を読み取り、申請テンプレート（Excel）に自動で転記します。これにより、本来は手作業で時間のかかる申請書類づくりを、AIによる読み取り＋人手での最終確認という形に省力化しています。AIが読み取った内容には誤りが含まれる可能性があるため、**最終的な書類確認は必ず人手で行います**（特に金額と日付）。

## 2. 業務の全体フロー

案件が発生してから事務局に書類を提出するまでの流れは次のとおりです。**自動**と書いてある部分はシステムが自動で行い、**手動**と書いてある部分は人が行います。

```
1. 支援事業者（営業窓口）が送客フォームを送信
      ↓（自動）
2. 案件管理表（Googleスプレッドシート）にデータが自動転記される
   同時に Google Drive に顧客フォルダが自動作成される
      ↓（手動）
3. 案件管理表でステータスを更新しながら進捗管理する
      ↓（自動 + 手動）
4. 資料を回収する
   ・ヒアリングシート / 登記簿 / 決算書 / 賃金台帳 など
   ・補助金関連メールの添付ファイルは Drive に自動格納される（15分おき）
      ↓（手動）
5. 書類自動作成ツール（Streamlit）で申請書類を作成する
   ・AIが資料を読み取り、申請テンプレートに転記
      ↓（手動）
6. 出力された書類を人手で目視確認する（金額・日付は必須チェック）
      ↓（手動）
7. 交付申請を行い、事務局へ提出する
```

### 自動の部分と人手の部分

| ステップ | 自動 | 人手 |
|---------|------|------|
| 送客フォーム → 案件管理表への転記 | ○ | |
| 顧客フォルダ（Drive）の作成 | ○ | |
| 送客通知（チャット） | ○ | |
| 案件管理表のステータス更新・進捗管理 | | ○ |
| 補助金関連メール添付ファイルの Drive 格納 | ○（15分おき） | |
| 賃金台帳などの資料回収 | | ○ |
| ツールでの書類作成（AI読取・テンプレ転記） | ○（実行は人が押す） | |
| 出力書類の目視確認 | | ○ |
| 交付申請・事務局提出 | | ○ |

補足:

- 送客フォームを送ると、案件管理表（シート1）に企業名・申請枠・支援事業者名・連絡先が自動入力され、進捗管理用のプルダウンやチェックボックスも自動設定されます。管理表への反映には数秒〜十数秒かかります。
- 案件管理表のステータスは「初回電話案内（未）→ 申請_資料待ち → 申請_CB準備中 → 申請_準備完了 → 交付申請 申請済 → 交付決定（または不採択）→ …→ 補助金 交付済」と進行に合わせて手で更新します。
- 補助金関連メールの添付ファイルは、特定のラベルがついたメールを対象に15分おきに Drive の該当フォルダへ自動格納されます。送信元や件名から自動で振り分けられます。

## 3. 登場する道具の地図

業務で使う主な道具は次のとおりです。それぞれの詳しい中身・操作は各ページを参照してください。

| 道具 | 役割（1行） | 詳しくは |
|------|------------|---------|
| Streamlit Cloud のツール | 本番運用中の書類自動作成ツール。資料を読み込ませると申請書類（Excel）を生成する | [03 ツールの仕組みと使い方](03_ツールの仕組みと使い方.md) |
| Claude Code のスキル（wagebook-convert） | 賃金台帳PDF（テキスト・手書き・画像）を、ツールが読める Excel に変換する標準経路（2026-07-21〜。ツールの自動変換は速さ優先時の代替） | [04 賃金台帳の実務と落とし穴](04_賃金台帳の実務と落とし穴.md) |
| Googleスプレッドシート（案件管理表） | 案件のステータス・申請枠・支援事業者などを一覧管理する台帳 | [06 運用ルールと体制](06_運用ルールと体制.md) |
| Google Drive | 顧客ごとの資料置き場・成果物（出力書類）の格納先 | [03 ツールの仕組みと使い方](03_ツールの仕組みと使い方.md) |
| GAS（Google Apps Script） | 送客時の自動通知、メール添付ファイルの Drive 自動格納などの自動処理 | [06 運用ルールと体制](06_運用ルールと体制.md) |

制度そのもの（R215/R216 や加点措置などの算定ルール）については [02 制度知識ベース](02_制度知識ベース.md)、実案件から得た教訓は [05 実案件から得た教訓](05_実案件から得た教訓_抽象化.md)、用語の定義は [99 用語集](99_用語集.md) を参照してください。
