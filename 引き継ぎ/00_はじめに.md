# 00 はじめに（補助金業務 引き継ぎコンテキストパック）

このフォルダ（`引き継ぎ/`）は、デジタル化・AI導入補助金（旧IT導入補助金）の申請支援業務について「我々が分かっていること」を、別の担当者と、そのPCのAI（Claude Code 等）が理解できる形にまとめた引き継ぎ用のコンテキスト集です。事実ベースで、個人情報・顧客情報は除いてあります。

最終更新：2026-06-19。

---

## 3分で全体像

- 何の業務か：中小企業の「デジタル化・AI導入補助金（旧IT導入補助金）」の**申請書類づくりを代行・自動化**する仕事。
- どう回しているか：顧客の送客 → 案件管理表（スプレッドシート）と顧客フォルダ（Drive）が自動でできる → ヒアリングシート・登記簿・決算書・賃金台帳を回収 → **ツール（Streamlit）が申請書類を自動生成** → 人が確認 → 交付申請して事務局へ提出。
- 一番むずかしいところ：**賃金台帳から R215（従業員数・FTE換算）と R216（給与支給総額）を正しく出すこと**。ここが補助率（1/2 → 2/3）や賃上げ要件に直結し、ミスが返還リスクになる。
- 道具：本番ツールは Streamlit Cloud で動作（修正は GitHub の main に push すると自動反映）。賃金台帳PDFの変換には Claude Code のスキル `wagebook-convert` を使う。

詳しくは [01 補助金とは・業務の全体像](01_補助金とは_業務の全体像.md) から。

## このパックの使い方・扱いの注意

- このパックは**配布用**。顧客企業名・個人氏名・賃金や財務の実額は含めていません（個人は役割表現に置換、金額は構造だけ残す方針）。
- 制度の一次根拠（公募要領・交付申請マニュアルのPDFリンク）は [02 制度知識ベース](02_制度知識ベース.md) 末尾にまとめています。迷ったら一次資料を確認。
- 事務局に未確認の「グレー解釈」は [05](05_実案件から得た教訓_抽象化.md) に ★グレー を付けています。我々が現時点で事実と認識しているものですが、案件で当たったら事務局確認を。
- ここに書かれた内容で「これは事実と違うのでは」と気づいたら、直して共有してください（共有のしかたは下記）。

## 更新と共有のしかた（チーム運用）

- このパックは「管理者がマスタを1か所で管理 → ZIP で配布」の運用です。各自は配布された ZIP を解凍し、自分の補助金フォルダで使います。
- 誤りや追記に気づいたら、チャットで管理者（自動化ツール担当）に次の形で送ってください：ファイル名（例: 02_制度知識ベース.md）／どの見出し・箇所か／現状の記述／こう直したい案。このチャットが「修正が来た」通知になります。
- 管理者がマスタを直し、この 00 の更新日を上げて新しい ZIP を再配布します。受け取った側がこのフォルダを直接書き換えても、次の配布で上書きされるので、必ずチャットで依頼してください。
- 配布物（ZIP）は `scripts/build_handoff_zip.py` で生成します（管理者のマスタから自動・許可リスト方式で顧客実データは含めません）。
- 機密の扱い：顧客実データ（賃金台帳・決算書・ヒアリングシート）や個人情報を、このパックや共有・チャットに**入れない**でください。詳細は [06 運用ルールと体制](06_運用ルールと体制.md)。
