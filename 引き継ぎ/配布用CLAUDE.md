# 補助金業務（このフォルダについて）

このフォルダは「デジタル化・AI導入補助金（旧IT導入補助金）」の申請支援業務の引き継ぎ一式です。補助金に関する質問・作業のときは、まず `引き継ぎ/00_はじめに.md` を読んでください。

> このファイルは Claude Code が自動で読み込む索引です。詳しい知識は `引き継ぎ/` 配下に分けて置いてあり、必要に応じてそこを読みます。

## Claude Code への案内（どこを読むか）

補助金の質問が来たら、内容に応じて次のファイルを読んでから答えること。憶測で答えない。

- 全体像・業務の流れ → `引き継ぎ/01_補助金とは_業務の全体像.md`
- 制度ルール（R215/R216・加点・賞与・役員除外・対象外法人など、数値や定義の判断） → `引き継ぎ/02_制度知識ベース.md`
- ツール（Streamlitの4タスク・モジュール役割・運用フラグ） → `引き継ぎ/03_ツールの仕組みと使い方.md`
- 賃金台帳の実務と落とし穴・賃金台帳の変換 → `引き継ぎ/04_賃金台帳の実務と落とし穴.md` ＋ wagebook-convert スキル
- 申請ポータル操作・事務局確認・実案件の教訓・セカンドオピニオン加点 → `引き継ぎ/05_実案件から得た教訓_抽象化.md`
- セカンドオピニオン加点の面談準備を実際に回す（ヒアリングシート・想定問答・入力文/確認メール生成プロンプト・記入見本） → `docs/セカンドオピニオン加点/配布物テンプレ/` と `docs/セカンドオピニオン加点/_sample/`（使い方は 05 の §4）
- 連絡窓口・定例・機密の扱い・デプロイ手順 → `引き継ぎ/06_運用ルールと体制.md`
- 用語が分からないとき → `引き継ぎ/99_用語集.md`

制度の数値（R215/R216の定義、最低賃金+63円、暦月固定など）は1文字違うと申請が狂うので、`引き継ぎ/02` と、必要なら 02 末尾の公募要領リンク（一次資料）で裏取りする。

## 使い始め（人間向けセットアップ）

1. 賃金台帳PDFを変換するスキルを使うなら、補助金書類作成ツールのUI（「📘 賃金台帳の作成手順」）から `wagebook-convert.zip` をダウンロードし、`~/.claude/skills/wagebook-convert/` に展開する（このスキルはコンテキストとは別配布）。Claude Code を再起動すると `/wagebook-convert` が使えるようになります。
2. この補助金フォルダの直下で Claude Code を開き、そのまま質問・作業する（このファイルが自動で読み込まれ、上の案内に従って必要なファイルを読みます）。

## 修正したいとき（内容の更新）

このパックは「マスタを1人が管理 → 配布」の運用です。気づいた誤りや追記は、次の形でチャットで管理者（自動化ツール担当）に送ってください。

- ファイル名（例: 02_制度知識ベース.md）
- どの見出し・箇所か
- 現状の記述
- こう直したい、という案

管理者がマスタを直し、更新日を上げて新しいZIPを再配布します。受け取った側がこのフォルダを直接書き換えても、次の配布で上書きされる点に注意（必ずチャットで依頼してください）。

## 機密情報の扱い（重要）

- 顧客の実データ（賃金台帳・決算書・給与明細・ヒアリング結果など）や、顧客企業名・個人氏名・賃金実額を、このフォルダや共有・チャットに入れないこと。
- このパックは事実ベースで脱PII化してあります（個人名は役割表現、金額は一般化）。同じ方針を、ここで作る作業ログ・メモにも適用してください。

## このCLAUDE.mdの置き場所について（上書き注意）

このファイルは、補助金フォルダの直下（ルート）に `CLAUDE.md` として置かれている前提です。もし既に自分の `CLAUDE.md` を補助金フォルダ直下に持っている場合は、同じ場所に置くと上書きになります。その場合はこのファイルを丸ごと置き換えず、上の「Claude Code への案内」ブロックを自分の `CLAUDE.md` に追記してください。
