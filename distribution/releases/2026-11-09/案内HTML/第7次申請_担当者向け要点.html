4. 今日やること

  1. 案件ごとに、実際に申請する日を決める。申請月が変われば加点②の直近月も変わる。
  2. ツールとプラグインの版を確認する（2.の表）。
  3. 顧客に、5.の年月をすべて含む賃金台帳・資料を依頼する。「直近2期分」のような冊数ではなく年月で依頼する。
  4. 過去の交付決定を、補助金名の年度（IT導入補助金2022〜2025）と枠で確認する。交付決定日の年で判断しない。
  5. 給与0年度目の見込みと1〜3年度目の計画を顧客と決め、根拠（当期の実績月、残りの月の見込み、賞与・昇給の予定）を案件フォルダに残す。
  6. 賃上げが必須の申請では、1年後と年平均の両方を含む賃上げ計画を交付申請までに従業員へ表明してもらい、実施日と方法を記録する。
  7. セカンドオピニオンの加点を使う場合は、確認者との面談を終えてから交付申請を出す。

6. ツールが止まる・注意が出る場合と対処

  • 通常枠で、賃金台帳の月の見出しに年が入っていない（「1月」「2月」だけ）→ 見出しを「令和7年1月」「2025年1月」のように年付きにした台帳で、もう一度実行する。
  • 前事業年度の労働時間が、一部の人・月の分しかない → 足りない月の労働時間を回収する。役員以外は全員、月間平均時間（E列）か月別の時間を入れる（正社員も空欄にしない）。
  • 前事業年度の途中に入社・退社した人がいて、その人の入社前・退職後の月が空欄 → 名簿・入退社日などで在籍していないと確認できた月に、標準の賃金台帳テンプレート（年付きの月見出し）の月の欄で「非在籍」と書いて、もう一度実行する。給与ソフトの個人別の台帳（「N月度給与」の形）などほかの形式では「非在籍」を読まないので、標準テンプレートに移してから書く。非在籍の月は総労働時間から除かれる。空欄・0円の月は非在籍とみなさない。休職など在籍していて給与のない月は空欄のまま止まるので、管理者に相談して個別に対応する。
  • 「非在籍」と書いた月に給与や労働時間がある → どちらが正しいかを原本で確かめて直す。
  • 給与0〜3年度目の計画、交付歴、表明が未確認 → 顧客に確認して入力する。
  • 画面と加点用台帳で、申請月・事業場の所在地が違う → 正しい値にそろえる。
  • 加点用台帳（7次以降版）の時間換算の対象月額（AH〜AT列）が空欄の月がある → 加点の判定は「未確定」になる。その月の賃金から6種（賞与・割増賃金・通勤手当など）を除いた額を入れる。基本給と職務手当などの手当は含め、基本給に含まれる固定残業代（みなし残業代）は除く（手当がなく固定残業代も含まない人は基本給と同じ額）。歩合給・出来高給がある人は 変更点と使い方 の6.の式で入れる。基本給はF〜R列に入れ、様式の【基本給】欄はツールがそこから作る。
  • 対象月額が基本給より少ない月があるという注意が出る → 判定は止まらない。基本給に固定残業代が含まれる、欠勤控除がある、列の取り違えのどれかを原本で確かめ、取り違えなら直し、それ以外は理由を記録する（対象月額を基本給に合わせて引き上げない）。
