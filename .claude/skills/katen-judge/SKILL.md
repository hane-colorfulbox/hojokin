# 加点判定スキル

## 第7次以降の適用（2026-11-04）

[変更点と使い方](docs/第7次申請_変更点と使い方.md) と [確認待ち事項](docs/第7次申請_確認待ち事項.md)、[公式資料で判断できることと確認の範囲](docs/第7次申請_公式資料で判断できることと確認の範囲.md) を先に確認する。給与0年度目は見込み値（窓口担当が事務局に照会して確認済み）。給与の当期見込みと生産性の前事業年度実績を分け、過去交付歴・表明・対象人数・根拠の未確認をAIで埋めない。効果報告の比較基準は未確定で、今回は申請向け対応まで。

以下の加点条件は第7次以降用。第1〜6次の訂正・再出力には旧版を使い、公募回・実申請月・原本版を明示する。過去の検証日・会議発言・実装経緯は当時の記録であり、新要件の裏取りとして流用しない。

## 0. このスキルが扱うタスク

賃金台帳PDF →（工程A）**加点判定用賃金台帳** Excel →（工程B）**加点①②の判定＋公式提出シート①②の生成**、までを一気に行う。

- 加点措置①（通常枠では加点項目14。インボイス対応類型は11、電子取引類型は8、セキュリティ対策推進枠は9）：令和7年10月〜令和8年9月の間で、「その期間の地域別最低賃金以上〜令和8年度改定の地域別最低賃金未満」で雇用している従業員が全従業員の30%以上である月が **3か月以上**（連続不要）。通常枠ではこの条件で補助率が 1/2→**2/3** に上がる。**補助率の引上げは通常枠だけ**で、他の枠は加点だけ。
- 加点措置②（通常枠では加点項目15。インボイス対応類型は12、電子取引類型は9、セキュリティ対策推進枠は10）：交付申請の直近月（申請月の前月）の事業場内最低賃金（時間換算給与の最小値）を、**令和8年6月の事業場内最低賃金＋55円以上**にしていること。
- 根拠は第7回以降の各枠の公募要領（通常枠は印刷p.16の補助率表、印刷p.25の項目14・15）。項目番号は枠で違うので、報告では「通常枠の項目14」のように枠を添える。
- 判定エンジンと公式様式の書き込みはツール（Streamlit）と**同一のコード**（同梱の `hojokin/` モジュール）を使う。手計算とツールで結果が食い違う事故を構造的に防ぐ。

**R215/R216用の標準賃金台帳（wagebook-convert の出力）とは別物**。標準台帳は総支給ベース・事業年度並びで、基本給・暦月固定列を持たないため加点判定には使えない（詳細: [reference/加点判定の制度要点.md](reference/加点判定の制度要点.md)）。

### 1.2 転記ルール

**母数（誰を台帳に入れるか）**

- 加点①②の母数は、**各月の「常時使用する従業員」**。公式①②の作業要領の定義で、労働基準法第20条の「予め解雇の予告を必要とする者」のこと。小規模事業者の判定に使う「常時使用する従業員」と同じ定義（第7回以降の通常枠公募要領 印刷p.6）を、**月ごとに**当てはめる。給与指標の全月支給者・FTE（R215の「全月在籍」ルール）とは別物。
- 役員・事業主本人は入らない（下の「役員」「個人事業主」の項）。パート・アルバイトも、次の例外に当たらなければ入る。
- 解雇予告が要らない人（労働基準法第21条）は、その月の母数に入れない：日々雇い入れられる人、2か月以内の期間を定めて使用される人、季節的業務に4か月以内の期間を定めて使用される人、試の使用期間中の人。ただし、日雇いが1か月を超えて続けて使われた場合、期間雇用が決めた期間を超えて続けて使われた場合、試用が14日を超えた場合は母数に入る。
- 母数に入る人は、**その月にいれば必ず入れる**。基準月にしかいない退職者・直近月にしかいない新入社員も入れる（低時給者1名の見落としが判定を丸ごと覆した実例あり）。
- 対象月のすべてで母数に入らない人（日雇いだけの人など）は台帳に行を作らず、理由と根拠（雇用契約書・労働条件通知書など）を報告に書く。月によって入る・入らないが分かれる人や、判断がつかない人は、推測で外さず「未確定」として報告し、窓口担当・管理者に確認する（台帳にはこの区別を書く欄がない）。
- 休職などの事情がある人は、公式様式の備考欄に書く（公式①②の作業要領）。

**金額（基本給と時間換算給与）**

- 公式様式は【基本給】欄と【時間換算給与】欄が別で、時間換算給与は厚生労働省「最低賃金額以上かどうかを確認する方法」で出す（公式①②の作業要領の指定）。この方法では次の6種類だけを除き、職務手当・役職手当・資格手当など毎月決まって払う通常の手当は**含めて**時間あたりに直す：①臨時に支払われる賃金（結婚手当など）②1か月を超える期間ごとに支払われる賃金（賞与など）③時間外・休日・深夜の割増賃金 ④精皆勤手当 ⑤通勤手当 ⑥家族手当。
- 台帳のF〜Q列・R列（見出しは「基本給」）には、**時間換算の元になる月額**＝その月の基本給＋上の6種類以外の手当（職務手当など）を入れる。6種類以外の手当が無い人は基本給そのもの。第7次の台帳テンプレートの記入ルール（B7「時間換算の元になる月額（基本給と、職務手当など毎月決まって払う通常の手当）」）と同じ考え方。総支給・課税支給合計・残業代・賞与を入れるのは誤り（時間換算給与が過大になり判定を歪める）。
- 🔴 **現行の台帳とエンジンの制約**：台帳には月ごとに1つの金額しか持てず、エンジンはその金額から様式の【基本給】欄（そのまま）と【時間換算給与】欄（金額÷その月の労働時間）の両方を作る。そのため、6種類以外の手当がある人は、様式の【基本給】欄に手当込みの額が入り、本来の基本給より大きく出る。逆に台帳へ基本給だけを入れると、時間換算給与が厚労省の方法より低く出て、①は対象者を多く数えて補助率2/3を誤って主張しやすくなり、②は事業場内最低賃金がずれる。
- 6種類以外の手当がある人が1人でもいる案件では、次の2つを手で行う。
  1. その人の各対象月について、原本の基本給・手当の内訳と、厚労省の方法で手計算した時間換算給与（月給制なら「（基本給＋6種類以外の手当）÷1か月平均所定労働時間」。時給制・日給制で手当がある場合は厚労省のページの計算例に沿う）を、様式の行（No）と月ごとに報告へ並べ、エンジンの時間換算給与と一致するか確かめる。食い違えば台帳の金額か時間を直して判定し直す。
  2. 提出用の様式は、その人の【基本給】欄を原本の基本給に直してから使う。直すのは Excel で該当セルを上書きする方法で行う（openpyxl で保存しない）。様式の判定式は【時間換算給与】欄だけを使い【基本給】欄は使わないので、判定は変わらない。直したファイルは §2 の原本無改変チェックの対象外になるので、直したセルの一覧を報告に残す。

**そのほかの転記ルール**

- **役員は台帳に入れない**（履歴事項全部証明書と突合して確定。辞任後に従業員として稼働する二重身分に注意）。
- **個人事業主の案件には履歴事項全部証明書が無い**。暫定ルールとして、**事業主本人は役員相当として台帳に入れない／青色事業専従者は従業員として入れる**（R216 側の扱い＝wagebook-convert SKILL.md §2.3 と揃える）。ただしこれは事務局に確認した扱いではない。**🔴 事業主本人を入れるか外すかで、30%判定の母数と事業場内最低賃金のMINが両方動き、加点①②の結論が反転しうる**。専従者が最低賃金層にいる案件では、判定を「暫定」と明示して顧客・窓口担当に確認する。
- **時給制・日給制**：月別の実労働時間を S〜AD / AE に必ず入れる。E列の固定値や他月の値で代用しない。日給者は確認済みの日次（金額÷時間）で時給を確定し、月合計÷月時間で検算。
- **時間の印字がない月**：「時給不明→除外」で放置しない。タイムカード・出勤簿等を確認し、他月の時給を使う場合も対象月への適用を原本・契約等で確認する。日額との割切れや複数月の一貫性だけで時間を確定しない。確認できなければ未確定として提出用確定出力を**停止**する。
- **月給制**：E列＝就業規則等で確認した、その人・対象月に適用する所定労働時間。月別時間の省略は、この代表所定時間が確認済みで各省略月にも適用可能な場合だけ。取れなければ時間不明として未確定。173.33h・160h等の仮定値や、AIが計算した月次時間の中央値・平均値で欠損を補完しない。確認済みの所定時間が得られるまで提出用確定出力を止める。
- 対象暦月のデータが台帳に無い場合は空欄のまま（勝手に補完しない）。**在籍確認済みだが資料不足、勤務時点・在籍自体が不明、非在籍確認済みを区別する**。勤務時点不明を単なる「データなし」や非在籍として母数から外さない。空欄・0円を非在籍と推定しない。入退社日や名簿等で**非在籍が確認済みの月だけ**、その月の基本給セルに文字列「非在籍」を入れる。未回収・在籍不明・時給不明が残る月は未確定として報告する。
- ⚠ **加点判定用台帳の出力ブックには「原本転記」シートを追加しない**。標準賃金台帳と違い、加点台帳のリーダーは「加点判定用明細」シート名と回別の年月を検証する。別シートを自動で同じ台帳と見なさない。原本の参照は標準台帳ブック側の原本転記シート群で行う。

### 1.3 工程Aの検算（工程Bの前に必ず）

[docs/チェックリスト_加点判定.md](docs/チェックリスト_加点判定.md) の **B（母集団の網羅性）・C（時給の導出）** を実行し、項目ごとに結果を報告する。最低限：

- ロスター（名簿・標準台帳）×賃金台帳PDF全ページの突合で未マッチ0
- 各月の母数が「常時使用する従業員」になっているか（役員・事業主本人、解雇予告が要らない人＝日雇い・2か月以内の期間雇用・試用14日以内などを入れていないか。外した人と理由の一覧）
- 基準月・直近月それぞれの在籍者スナップショットと、片方にしかいない人の明示リスト
- 6種類以外の手当（職務手当など）がある人の有無。ある場合は §1.2 の手計算の結果と、エンジンの時間換算給与との差
- 全員の時間換算給与と、その勤務地・発効日の法定最賃を確認（割れは抽出ミス・時間欠落・期間またぎ等の確認対象で、即違法と断定しない）
- 55円境界の丸め：時間は小数第4位まで保持

## 2. 工程B: 判定＋公式提出シート生成

```
# 判定レポートのみ
python "${CLAUDE_SKILL_DIR}/review/run_katen_judge.py" "加点判定用台帳.xlsx" --call-round 7

# C3が未入力の台帳に申請月を渡す場合
python "${CLAUDE_SKILL_DIR}/review/run_katen_judge.py" "台帳.xlsx" --app-month 2026/11 --call-round 7

# 公式様式①②も生成（申請枠で①のテンプレが変わる）
python "${CLAUDE_SKILL_DIR}/review/run_katen_judge.py" "台帳.xlsx" --fill 通常 --company 株式会社サンプル --call-round 7
python "${CLAUDE_SKILL_DIR}/review/run_katen_judge.py" "台帳.xlsx" --fill インボイス --outdir 出力先 --call-round 7
```

- 🔴 `--call-round` は**判定だけのときも必ず付ける**（実際に申請する公募回。第7次は `7`、第8次は `8`）。付け忘れるとドライバは終了コード2で止まる。交付申請月が2026年11月以降なのに公募回が6以下のときも止まる（第7次の案件を第1〜6次＝旧回のルールで判定しないため）。レポート冒頭の「公募回」が実際の回と一致しているかも確かめる。
- 判定エンジンはツールと同一（`hojokin.wage_reader.judge_bonus_points`）。ただしツール（Streamlit）で第7次の加点判定をするのは、画面フッターの版が v0.2.99 以上（第7次対応版）のときだけ。役員除外・整数整合（時間換算給与は円で丸めて比較）・>0だけで法定下限を満たすとは扱わず、地域・発効日別の確認を別に行う。エンジンの時間換算給与は「台帳の金額÷労働時間」なので、6種類以外の手当がある案件は §1.2 の手計算と突き合わせ、様式の【基本給】欄を直す。
- `--fill` の出力は**原本ZIP丸ごとコピー＋対象セルの値だけ差し替え**（外科的パッチ）。公式様式の図形・記入例画像・判定式・秘密度ラベルを壊さない（openpyxl 再保存は使わない）。
- 生成したら様式ごとに `python "${CLAUDE_SKILL_DIR}/review/check_lossless.py" <原本> <出力>` で原本無改変を確かめ、結果を完了報告に含める（原本のパスは、ドライバの出力の「様式①生成: …（原本: …）」に出る）。
- ②は交付申請月が無いと生成されない（レポートにその旨が出る）。
- 様式②の最低賃金欄（E列・M列）は合否に使われず、令和7年度の額だけを表示する（直近月が令和8年度改定の発効後でも同じ。山形は1,031円と誤表示）。原本は直さず、適用した法定額と発効日を説明メモに書く。公式②で Excel の「データ」→「すべて更新」は実行しない（表示が令和6年度の額に戻るおそれ。詳細は reference/加点判定の制度要点.md）。
- レポートの `⚠` 行（notes）は**全件読み、放置しない**。特に「法定最低賃金を下回る従業員」警告は時間欠落・抽出誤りのシグナルで、未解消のまま提出物を出さない。

## 3. 感度チェックと停止条件

[docs/チェックリスト_加点判定.md](docs/チェックリスト_加点判定.md) の **E（感度チェック）** を必ず実行し報告に含める：

- 基準月MINより低い人が基準月に隠れていないか（時給不明者・除外者を含む**下位全員**を明示的に問う。基準月側は低いほど**有利**、直近月側は低いほど**不利**——差の向きに注意）
- 除外判断（役員・家族・名目給）を反転させた場合に判定が変わるか試算。変わるなら顧客確認を「必須」に格上げし、判定は暫定扱い
- 申請月が±1か月ずれた場合の影響と必要な追加資料

**停止条件**：最賃割れ警告が未解消／在籍・対象月に適用する時間・時給が未確認の従業員が残っている／除外反転で判定が覆るのに事実確認が未了／母数（常時使用する従業員）に入るかの判断がつかない人が残っている／6種類以外の手当がある人の時間換算給与を厚労省の方法で確かめていない、または様式の【基本給】欄を原本の基本給に直していない——のいずれかに該当する間は、提出用の様式①②を確定成果物として渡さない（未確定の理由を報告し、提出用様式の確定共有はしない）。仮定時間で判定が動かない試算でも停止条件は解除しない。
