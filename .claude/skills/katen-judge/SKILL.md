賃金台帳PDF →（工程A）**加点判定用賃金台帳** Excel →（工程B）**加点①②の判定＋公式提出シート①②の生成**、までを一気に行う。

### 1.2 転記ルール

- **金額は公式様式の入力定義に従って基本給欄へ転記する**。本給と通常手当を含む法定最賃算定賃金の関係に疑義があれば個別確認する。残業・通勤・精皆勤・家族手当・賞与を**混ぜない**。総支給や課税支給合計を入れるのは誤り（時間換算給与が過大になり判定を歪める）。
- **対象者は月ごとのスナップショット在籍**。R215の「全月在籍」ルールとは別物。基準月にしかいない退職者・直近月にしかいない新入社員も、その月に居れば必ず入れる（低時給者1名の見落としが判定を丸ごと覆した実例あり）。
- **役員は台帳に入れない**（履歴事項全部証明書と突合して確定。辞任後に従業員として稼働する二重身分に注意）。
- **個人事業主の案件には履歴事項全部証明書が無い**。暫定ルールとして、**事業主本人は役員相当として台帳に入れない／青色事業専従者は従業員として入れる**（R216 側の扱い＝wagebook-convert SKILL.md §2.3 と揃える）。ただしこれは事務局に確認した扱いではない。**🔴 事業主本人を入れるか外すかで、30%判定の母数と事業場内最低賃金のMINが両方動き、加点①②の結論が反転しうる**。専従者が最低賃金層にいる案件では、判定を「暫定」と明示して顧客・窓口担当に確認する。
- **時給制・日給制**：月別の実労働時間を S〜AD / AE に必ず入れる。E列の固定値や他月の値で代用しない。日給者は確認済みの日次（金額÷時間）で時給を確定し、月合計÷月時間で検算。
- **時間の印字がない月**：「時給不明→除外」で放置しない。タイムカード・出勤簿等を確認し、他月の時給を使う場合も対象月への適用を原本・契約等で確認する。日額との割切れや複数月の一貫性だけで時間を確定しない。確認できなければ未確定として提出用確定出力を**停止**する。
- **月給制**：E列＝就業規則等で確認した、その人・対象月に適用する所定労働時間。月別時間の省略は、この代表所定時間が確認済みで各省略月にも適用可能な場合だけ。取れなければ時間不明として未確定。173.33h・160h等の仮定値や、AIが計算した月次時間の中央値・平均値で欠損を補完しない。確認済みの所定時間が得られるまで提出用確定出力を止める。
- 対象暦月のデータが台帳に無い場合は空欄のまま（勝手に補完しない）。**在籍確認済みだが資料不足、勤務時点・在籍自体が不明、非在籍確認済みを区別する**。勤務時点不明を単なる「データなし」や非在籍として母数から外さない。空欄・0円を非在籍と推定しない。入退社日や名簿等で**非在籍が確認済みの月だけ**、その月の基本給セルに文字列「非在籍」を入れる。未回収・在籍不明・時給不明が残る月は未確定として報告する。
- ⚠ **加点判定用台帳の出力ブックには「原本転記」シートを追加しない**。標準賃金台帳と違い、加点台帳のリーダーは「加点判定用明細」シート名と回別の年月を検証する。別シートを自動で同じ台帳と見なさない。原本の参照は標準台帳ブック側の原本転記シート群で行う。

## 2. 工程B: 判定＋公式提出シート生成

```
# 判定レポートのみ
python "${CLAUDE_SKILL_DIR}/review/run_katen_judge.py" "加点判定用台帳.xlsx" --call-round 7

# C3が未入力の台帳に申請月を渡す場合
python "${CLAUDE_SKILL_DIR}/review/run_katen_judge.py" "台帳.xlsx" --app-month 2026/11 --call-round 7

# 公式様式①②も生成（申請枠で①のテンプレが変わる）
python "${CLAUDE_SKILL_DIR}/review/run_katen_judge.py" "台帳.xlsx" --fill 通常 --company 株式会社サンプル --call-round 7
python "${CLAUDE_SKILL_DIR}/review/run_katen_judge.py" "台帳.xlsx" --fill インボイス --outdir 出力先 --call-round 7
```

- 判定エンジンはツールと同一（`hojokin.wage_reader.judge_bonus_points`）。役員除外・整数整合（時間換算給与は円で丸めて比較）・>0だけで法定下限を満たすとは扱わず、地域・発効日別の確認を別に行う。
- `--fill` の出力は**原本ZIP丸ごとコピー＋対象セルの値だけ差し替え**（外科的パッチ）。公式様式の図形・記入例画像・判定式・秘密度ラベルを壊さない（openpyxl 再保存は使わない）。
- 生成したら様式ごとに `python "${CLAUDE_SKILL_DIR}/review/check_lossless.py" <原本> <出力>` で原本無改変を確かめ、結果を完了報告に含める（原本のパスは、ドライバの出力の「様式①生成: …（原本: …）」に出る）。
- ②は交付申請月が無いと生成されない（レポートにその旨が出る）。
- レポートの `⚠` 行（notes）は**全件読み、放置しない**。特に「法定最低賃金を下回る従業員」警告は時間欠落・抽出誤りのシグナルで、未解消のまま提出物を出さない。

## 3. 感度チェックと停止条件

[docs/チェックリスト_加点判定.md](docs/チェックリスト_加点判定.md) の **E（感度チェック）** を必ず実行し報告に含める：

- 基準月MINより低い人が基準月に隠れていないか（時給不明者・除外者を含む**下位全員**を明示的に問う。基準月側は低いほど**有利**、直近月側は低いほど**不利**——差の向きに注意）
- 除外判断（役員・家族・名目給）を反転させた場合に判定が変わるか試算。変わるなら顧客確認を「必須」に格上げし、判定は暫定扱い
- 申請月が±1か月ずれた場合の影響と必要な追加資料

**停止条件**：最賃割れ警告が未解消／在籍・対象月に適用する時間・時給が未確認の従業員が残っている／除外反転で判定が覆るのに事実確認が未了——のいずれかに該当する間は、提出用の様式①②を確定成果物として渡さない（未確定の理由を報告し、提出用様式の確定共有はしない）。仮定時間で判定が動かない試算でも停止条件は解除しない。
