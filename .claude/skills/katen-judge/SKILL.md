# 加点判定ローカル完結スキル（CC＝Claude Code 用）

## 0. このスキルが扱うタスク

賃金台帳PDF →（工程A）**加点判定用賃金台帳** Excel →（工程B）**加点①②の判定＋公式提出シート①②の生成**、までをローカルで一気に行う。

- 加点措置①（加点項目14）＝補助率 1/2→**2/3** のトリガー。令和6年10月〜令和7年9月の各暦月で「時間換算給与 < R7改定後の地域別最賃」の従業員が30%以上いる月が **3か月以上**（連続不要）。
- 加点措置②（加点項目15）＝事業場内最低賃金（時間換算給与のMIN）が **令和7年7月 → 交付申請直近月で +63円以上**。
- 判定エンジンと公式様式の書き込みはツール（Streamlit）と**同一のコード**（同梱の `hojokin/` モジュール）を使う。手計算とツールで結果が食い違う事故を構造的に防ぐ。

**R215/R216用の標準賃金台帳（wagebook-convert の出力）とは別物**。標準台帳は総支給ベース・事業年度並びで、基本給・暦月固定列を持たないため加点判定には使えない（詳細: `reference/加点判定の制度要点.md`）。

### 0.1 最初に必ずユーザーから取得する情報

| # | 項目 | 必須/任意 | 用途・補足 |
|---|---|---|---|
| 1 | 賃金台帳PDF（または記入済み加点判定用台帳Excel） | 必須 | ②のみなら基準月（令和7年7月）＋直近月の2か月分で可。①も見るなら令和6年10月〜令和7年9月の12か月分（**前事業年度を含む最大2期分**の台帳が要ることが多い） |
| 2 | 交付申請月 | 必須 | 直近月＝その**前月**。1か月ずれると判定月がずれ結果が変わる |
| 3 | 申請枠（通常 / インボイス・セキュリティ） | 必須 | ①の提出テンプレ選択に影響（②は全枠共通） |
| 4 | 事業場所在地の都道府県 | 必須 | 地域別最賃の参照先。勤務地が所在地と異なる従業員・派遣がいる場合は要相談 |
| 5 | 履歴事項全部証明書PDF | 推奨 | 役員の確定（就任・辞任日と対象月の前後関係）。**個人事業主には存在しない**ので §1.2 の暫定ルール（事業主本人=除外／専従者=算入）で進め、判定を暫定と明示する |
| 6 | 月給制従業員の月間所定労働時間（就業規則） | 推奨 | 取れなければ 173.33h（2080÷12）仮置き＋注記（§2） |

**標準台帳の「原本転記」シート群からの転用（任意・2026-07-26〜）**：同一案件で wagebook-convert が生成した**全項目の原本転記シート群**（基本給・手当内訳・労働時間が原本どおり載っているもの。wagebook-convert SKILL.md §4.1.2）が既にあれば、同じ PDF を二度読みせず、工程Aの**初期データソース**として使ってよい。ただし転記シートも AI 産物＝**真は PDF**。§1.3 の検算（賃金台帳PDF全ページとの突合で未マッチ0）は**省略不可**。転記が「課税支給額」等の集計行だけの旧形式なら転用せず PDF から読む。

### 0.2 スキルが判断できない事項（人間・顧客確認）

`{ROOT}/docs/チェックリスト_加点判定.md` の A（前提）・C'（事実確認）に従う。特に：家族・**事業主本人**・専従者・名目給の身分（従業員か役員か）／時間記録のない従業員のタイムカード有無／月給者の所定労働時間／勤務地≠所在地の適用最賃。**除外判断を反転させると判定が変わる人**がいる場合、顧客確認が済むまで判定は「暫定」と明示する。

## 1. 工程A: 加点判定用賃金台帳への変換

### 1.1 変換先テンプレート（レイアウトは固定・ヘッダー上書き禁止）

`{ROOT}/ツール/加点判定用賃金台帳テンプレート.xlsx` をコピーして使う（シート名「加点判定用明細」、ヘッダー6行目・データ7行目〜）：

| 列 | 内容 |
|---|---|
| B | No |
| C | 氏名 |
| D | 雇用形態（正社員/パート等。**役員は行ごと入れない**） |
| E | 月間所定労働時間（月給者の換算分母） |
| F〜Q | **暦月固定**：令和6年10月〜令和7年9月の**基本給** |
| R | 交付申請直近月の基本給 |
| S〜AD | 同暦月の**月別労働時間**（任意列。時給制・月変動者は必須） |
| AE | 直近月の月別労働時間 |
| C2 | 事業場所在地（都道府県） |
| C3 | 交付申請月（yyyy/mm） |

🔴 **列は暦月固定**。標準賃金台帳の「直近事業年度の12ヶ月並べ」とは**逆の**ルール（ここを取り違えるのが最大の落とし穴）。ヘッダー行（6行目）は書き換えない。

### 1.2 転記ルール

- **金額は基本給のみ**（所定内賃金）。残業・通勤・精皆勤・家族手当・賞与を**混ぜない**。総支給や課税支給合計を入れるのは誤り（時間換算給与が過大になり判定を歪める）。
- **対象者は月ごとのスナップショット在籍**。R215の「全月在籍」ルールとは別物。基準月にしかいない退職者・直近月にしかいない新入社員も、その月に居れば必ず入れる（低時給者1名の見落としが判定を丸ごと覆した実例あり）。
- **役員は台帳に入れない**（履歴事項全部証明書と突合して確定。辞任後に従業員として稼働する二重身分に注意）。
- **個人事業主の案件には履歴事項全部証明書が無い**。暫定ルールとして、**事業主本人は役員相当として台帳に入れない／青色事業専従者は従業員として入れる**（R216 側の扱い＝wagebook-convert SKILL.md §2.3 と揃える）。ただしこれは事務局に確認した扱いではない。**🔴 事業主本人を入れるか外すかで、30%判定の母数と事業場内最低賃金のMINが両方動き、加点①②の結論が反転しうる**。専従者が最低賃金層にいる案件では、判定を「暫定」と明示して顧客・窓口担当に確認する。
- **時給制・日給制**：月別の実労働時間を S〜AD / AE に必ず入れる（空欄だとE列固定値で換算され時間換算給与が歪む→判定エンジンが法定最賃割れ警告を出す）。日給者は日次（金額÷時間）で時給を確定し、月合計÷月時間で検算。
- **時間の印字がない月**：「時給不明→除外」で放置しない。他月の原本から時給を復元（日額が時給の整数倍か・複数月で一貫するか）。復元できなければタイムカードを依頼して**停止**。
- **月給制**：E列＝就業規則の所定労働時間。取れなければ 173.33h 仮置きとし、「その人が最低賃金層でない＝判定に影響しない」ことを確認したうえで注記に残す。
- 対象暦月のデータが台帳に無い場合は空欄のまま（勝手に補完しない）。エンジンが「対象月データなし」を警告で明示する。
- ⚠ **加点判定用台帳の出力ブックには「原本転記」シートを追加しない**。標準賃金台帳と違い、加点台帳のリーダー（`read_bonus_wage_ledger`）は「加点判定用明細」シートが見つからないと**先頭シートに無言フォールバック**する実装で、転記シートの読み飛ばしガードが無い。原本の参照は標準台帳ブック側の原本転記シート群で行う。

### 1.3 工程Aの検算（工程Bの前に必ず）

`{ROOT}/docs/チェックリスト_加点判定.md` の **B（母集団の網羅性）・C（時給の導出）** を実行し、項目ごとに結果を報告する。最低限：

- ロスター（名簿・標準台帳）×賃金台帳PDF全ページの突合で未マッチ0
- 基準月・直近月それぞれの在籍者スナップショットと、片方にしかいない人の明示リスト
- 全員の時間換算給与 ≥ その期の地域別最賃（割れたら抽出ミス・時間欠落のシグナル）
- 63円境界の丸め：時間は小数第4位まで保持

## 2. 工程B: 判定＋公式提出シート生成

```
# 判定レポートのみ
python "{SKILL_DIR}/review/run_katen_judge.py" "加点判定用台帳.xlsx"

# C3が未入力の台帳に申請月を渡す場合
python "{SKILL_DIR}/review/run_katen_judge.py" "台帳.xlsx" --app-month 2026/08

# 公式様式①②も生成（申請枠で①のテンプレが変わる）
python "{SKILL_DIR}/review/run_katen_judge.py" "台帳.xlsx" --fill 通常 --company 株式会社サンプル
python "{SKILL_DIR}/review/run_katen_judge.py" "台帳.xlsx" --fill インボイス --outdir 出力先
```

- 判定エンジンはツールと同一（`hojokin.wage_reader.judge_bonus_points`）。役員除外・整数整合（時間換算給与は円で丸めて比較）・>0下限も公式シートの判定式と一致。
- `--fill` の出力は**原本ZIP丸ごとコピー＋対象セルの値だけ差し替え**（外科的パッチ）。公式様式の図形・記入例画像・判定式・秘密度ラベルを壊さない（openpyxl 再保存は使わない）。
- ②は交付申請月が無いと生成されない（レポートにその旨が出る）。
- レポートの `⚠` 行（notes）は**全件読み、放置しない**。特に「法定最低賃金を下回る従業員」警告は時間欠落・抽出誤りのシグナルで、未解消のまま提出物を出さない。

## 3. 感度チェックと停止条件

`{ROOT}/docs/チェックリスト_加点判定.md` の **E（感度チェック）** を必ず実行し報告に含める：

- 基準月MINより低い人が基準月に隠れていないか（時給不明者・除外者を含む**下位全員**を明示的に問う。基準月側は低いほど**有利**、直近月側は低いほど**不利**——差の向きに注意）
- 除外判断（役員・家族・名目給）を反転させた場合に判定が変わるか試算。変わるなら顧客確認を「必須」に格上げし、判定は暫定扱い
- 申請月が±1か月ずれた場合の影響と必要な追加資料

**停止条件**：最賃割れ警告が未解消／時給を復元できない従業員が残っている／除外反転で判定が覆るのに事実確認が未了——のいずれかに該当する間は、提出用の様式①②を確定成果物として渡さない（「暫定」明記で共有は可）。
