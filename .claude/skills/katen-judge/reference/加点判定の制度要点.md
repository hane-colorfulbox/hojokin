# 加点判定の制度要点

更新日：2026-11-06。第7次以降用。第1〜6次の旧案件は元申請の版・原本・算定方式を保持する。

[変更点と使い方](../docs/第7次申請_変更点と使い方.md) と [確認待ち事項](../docs/第7次申請_確認待ち事項.md)、[公式資料で判断できることと確認の範囲](../docs/第7次申請_公式資料で判断できることと確認の範囲.md) を先に読む。

## 加点①・通常枠補助率引上げ

- 対象窓は2025/10〜2026/9（令和7年10月〜令和8年9月）。「その期間の地域別最低賃金以上〜令和8年度改定の地域別最低賃金未満」で雇用している従業員を数える。
- その従業員が全従業員の30%以上である月が3か月以上。3か月は連続でなくてよい。
- 補助率1/2→2/3への引上げは通常枠だけ。他枠の加点①を補助率引上げとして案内しない。
- 項目番号は枠で違う：通常枠14、インボイス対応類型11、電子取引類型8、セキュリティ対策推進枠9（第7回以降の各枠の公募要領）。
- 公式様式は、通常枠が「賃金状況報告シート（補助率引上げ・加点措置①用）」、それ以外の枠が「同（加点措置①用）」。どちらも第7回以降用（B2に【第７次公募回以降用】）を使う。申請月と選定3か月の年月を記入し、原本の証憑と照合する。

## 加点②

- 基準月は2026/6、比較先は実際の申請月の前月（公式②の N14＝EDATE(申請月,-1)）。事業場内最低賃金（時間換算給与の最小値）の差が55円以上で対象（公式②の判定式 D10）。
- 項目番号は枠で違う：通常枠15、インボイス対応類型12、電子取引類型9、セキュリティ対策推進枠10。
- 差54円は対象外、55円ちょうどは対象。東京・神奈川・大阪の令和8年度改定差は54円なので、法定最賃に合わせただけでは届かない。
- 直近月に令和8年度改定がまだ発効していない県では、法定どおりに上げても差は生じない。11月申請（直近月10月）では、山梨・徳島・愛媛・大分（11/1発効）、長崎（11/2）、佐賀（11/15）、京都（11/16）、岩手・熊本（12/1）、沖縄（12/2）の10県がこれに当たる。12月申請（直近月11月）でも岩手・熊本・沖縄は未発効、長崎・佐賀・京都は月の途中の発効になる（厚労省の令和8年度地域別最低賃金の一覧で確認）。
- 11月提出なら直近月10月、12月提出なら11月、翌1月なら前年12月。延期したら再回収・再判定。
- 基準月と直近月の在籍者は別。基準月にしかいない退職者・直近月にしかいない新入社員も、当該月の対象者として確認する。

## 母数と時間換算給与（公式①②の作業要領）

- 母数は各月の「常時使用する従業員」で、労働基準法第20条の「予め解雇の予告を必要とする者」のこと。小規模事業者の判定と同じ定義（第7回以降の通常枠公募要領 印刷p.6）を月ごとに当てはめる。役員・事業主は入らない。給与指標の全月支給者・FTEとは別。
- 日雇い・2か月以内の期間雇用・季節的業務で4か月以内の期間雇用・試用期間中の人は、解雇予告が要らない（労働基準法第21条）ので母数に入らない。ただし、日雇いが1か月を超えて、期間雇用が決めた期間を超えて、試用が14日を超えて続けて使われていれば入る。
- その月の母数に入る人は全員確認する。欠損者を除外して母数を縮めない。
- 時間換算給与は厚労省「最低賃金額以上かどうかを確認する方法」で出す（公式の指定）。除くのは6種類（臨時に支払われる賃金、1か月を超える期間ごとに支払われる賃金＝賞与など、時間外・休日・深夜の割増賃金、精皆勤手当、通勤手当、家族手当）だけで、職務手当などの手当と歩合給・出来高給は含める。歩合・出来高分はその月の総労働時間で割って時間額にする。基本給に含まれる固定残業代（みなし残業代）は割増賃金に当たるので除く。様式は【基本給】欄と【時間換算給与】欄が別。
- 第7次以降の台帳は金額を2つの欄に分ける。F〜R列＝基本給（本給だけ。固定残業代を含む基本給は原本の額のまま）で、様式の【基本給】欄にそのまま書く。AH〜AT列＝時間換算の対象月額（その月の賃金から6種類を除いた額。基本給に含まれる固定残業代は除く。手当がなく固定残業代も含まない人は基本給と同じ額。歩合給・出来高給がある人は「歩合・出来高以外の対象額＋歩合・出来高分×（台帳の労働時間÷その月の総労働時間）」）で、時間換算給与＝対象月額÷その月の労働時間を【時間換算給与】欄に書く。様式の【基本給】欄の手直しは要らない（SKILL.md §1.2）。対象月額・基本給が空欄の月は未確定。対象月額が基本給より少ない月は未確定にせず注意を出すので、固定残業代・欠勤控除・列の取り違えのどれかを原本で確かめる。様式の判定式は【時間換算給与】欄だけを使う。
- AH〜AT列がない台帳（第1〜6次の旧回用、または第7次の古いテンプレートで作ったもの）は、F〜R列の1つの月額から両方の欄を作る。第7次なら最新の台帳テンプレートに移す。第1〜6次の訂正は旧回の記入ルールどおりで、通常の手当を含めた人は様式の【基本給】欄を原本の基本給に直す。

## 最賃・様式・入力範囲

- 加点①のR8固定上限と、各月の法定下限・勤務地・発効日を分ける。発効日は都道府県ごとに違う（令和7年度改定は2025/10〜2026/3、令和8年度改定は2026/10〜12に分かれる）。全国10/1一斉発効とは扱わない。
- 公式②の最低賃金欄（E列・M列）は合否に使われない（判定は時間換算給与の最小値の差だけ）。②の表示用マスタは令和7年度の単一値なので、直近月が令和8年度改定の発効後でも令和7年度の額を表示する（例：東京は直近月が2026/10以降でも1,226円と表示。法定は1,280円）。原本は直さず、適用した法定額と発効日を説明メモに書く。差し替えるのは公式の更新版が出たときだけ。
- 公式②のマスタは、厚労省の一覧と次の4点が食い違う（2026-11-05照合）。秋田の発効日（②は2026/3/1、正しくは2026/3/31）、福島の発効日（②は2025/1/1、正しくは2026/1/1）、広島の発効日（②は2025/12/1、正しくは2025/11/1）、山形の金額（②は1,031円、正しくは1,032円。公式①のマスタは1,032円で正しい）。法定の確認は厚労省・労働局の一覧で行い、原本の表示とは区別する。
- 月途中発効・賃金計算期間またぎ・複数県・派遣先は、月平均と会社1県で適合／違反を確定せず個別確認へ。
- 所定時間を仮置きして提出用判定を確定しない。
- 月別時間の省略は、E列の代表所定時間が確認済みで、その人の各省略月に適用できる場合だけ。時給制・日給制・月変動者は各月の確認値を使う。173.33h・160h等の仮定値や、AIが計算した月次時間の中央値・平均値・他月値による欠損補完では提出不可。
- 空欄は未回収・非在籍・無支給を原本で区別。在籍確認済みの資料不足と、勤務時点・在籍自体が不明な状態も分ける。在籍不明を「データなし」として母数から外さない。非在籍は入退社日・名簿等で確認した月だけ明示し、未確定が残る間は対象／対象外を断定せず、提出用確定出力を止める。

## 回収範囲と版の指定

必要資料は加点①窓＋②基準月＋実申請前月を全て覆うもの。前期・今期の2冊に固定せず、3事業年度にまたがる例も確認する。専用台帳の基本給列・時間列・時間換算の対象月額列の年月は公募回と照合する。

第7次以降は専用台帳・公式3様式を「第7次以降」フォルダから選び、ドライバへ `--call-round 7` 等の実公募回を渡す（判定だけの実行でも省略しない）。旧互換定数や旧ファイル名の後勝ち探索で版を推定しない。

公式原本は保存し、提出物側の入力セルだけ変更する。氏名欄の残存サンプルを消した後は再読取で空欄を確認。

公式②では Excel の「データ」→「すべて更新」を実行しない。②の表示用の最低賃金マスタは、隠しシート「元データ」（令和6年度の値）を読み込む作り（Power Query）なので、実行すると表示が令和6年度の額に戻るおそれがある（Excel での実際の動きは未確認）。数式の再計算は「すべて更新」とは別の操作。
