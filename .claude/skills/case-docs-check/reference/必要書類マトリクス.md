# 必要書類マトリクス（デジタル化・AI導入補助金2026）

## 第7次以降の適用（2026-11-04）

[変更点と使い方](../docs/第7次申請_変更点と使い方.md) と [確認待ち事項](../docs/第7次申請_確認待ち事項.md)、[公式資料で判断できることと確認の範囲](../docs/第7次申請_公式資料で判断できることと確認の範囲.md) を先に確認する。給与0年度目は見込み値（窓口担当の事務局照会回答をユーザーが提示済み）。給与の当期見込みと生産性の前事業年度実績を分け、過去交付歴・表明・対象人数・根拠の未確認をAIで埋めない。効果報告の比較基準は未確定で、今回は申請向け対応まで。

case-docs-check スキルの判定正典。**一次資料（公募要領・交付申請マニュアル）で裏取りした要件**と、
社内運用の要件（ヒアリングシート「確認事項」シート・回収フロー）を区別して記載する。

### 賃金台帳・見込みの用途別対象期間

- 実績台帳は指定した実績事業年度の12か月を転記する。給与0年度目は当期見込みで、前期実績の自動流用や未到来月の0円化をしない。
- 第7次以降の全4原本で給与0〜3年度目の総額・FTE・根拠・確認状態を入力する。率の達成義務・表明・任意加点の有無と入力必須は別。通常枠は公式FAQ No.39、他枠は申請マニュアルp.89・91に基づく。
- 対象者は各算出対象年度の全月支給者。途中採用・退職で全月支給がない年度だけ除外し、パート等は正社員時間換算、福利厚生等による所定の時短勤務者は除外可。公募要領p.7〜8に定義済みで一般照会は不要。個別の支給・在籍・時間が不足する場合はその値だけ確認する。回収票の最終形は社内運用調整と分ける。
- 生産性の基準（0年度目）は前事業年度実績、給与0年度目は申請当年度見込み。計画1〜3年度目は両指標とも申請翌事業年度・翌々事業年度・3期後で同じ期間となる。違うのは基準年度であり、計画1年度目を申請当年度にしない。
- 通常枠の生産性は前事業年度の損益・人件費・減価償却費・総労働時間の実績に加え、計画1年度目＝申請翌事業年度から3年度目＝申請3期後までの確認済み計画（営業利益・人件費・減価償却費・総労働時間・根拠・確認状態）を回収。給与0年度目と別データにする。通常枠150万円未満・任意賃上げなしでも生産性計画は省略しない。
- 生産性の初年度・3年平均3%／過去指定枠交付あり4%を検算する。旧B42の「初年度3%かつ3年目の前年比9%」によるOK表示を根拠にせず、未確認計画があれば該当申請書の提出用確定出力を止める。
- 個人事業主は暦年。公募回・実際の申請日が変わると給与0年度目も変わる場合がある。

## 6. 枠・様式の対応（取り違え検知の正典）

| 案件の枠 | ヒアリング様式 | 申請書テンプレ |
|---|---|---|
| 通常枠・法人 | ヒアリングシート2026_通常枠法人 | 通常枠_2026 |
| 通常枠・個人 | ヒアリングシート2026_通常枠個人 | 通常枠_個人_2026 |
| インボイス枠・法人 | ヒアリングシート2026_インボイス法人 | インボイス枠_2026 |
| インボイス枠・個人 | ヒアリングシート2026_インボイス個人 | インボイス枠_個人_2026 |

- **通常枠は個人事業主も申請できる**（公募要領の補助対象者に法人格の限定なし）。様式・テンプレは
  2026-08-10 に整備し、2026-08-17 に原本管理担当者作成の正本（設問改訂版）へ追随した。
  それ以前は「通常枠は法人のみ」と書いていたが誤り。
- **セキュリティ対策推進枠のテンプレ・様式は社内に存在しない**（ツール対象は上記4通りのみ）。
  セキュリティ枠らしき案件は「本ツール群の対象外」と報告する。
- 2つの個人様式（通常枠個人／インボイス個人）は基本情報の上半分が完全に同じで、見た目では
  区別しにくい。判別は r31 の設問文言（通常枠=「業務上の課題」／インボイス=「時間がかかって
  いる業務」）と r84/r85 で行う（`review/check_docs.py` の `HEARING_FORMS`、2026-08-17 再実測）。
- 様式取り違え（例: 通常枠様式でインボイス案件）は転記の広域ズレ（実事故あり）→ ❌最優先で報告。

## 7. 未裏取り・グレー（断定しない項目）

| 項目 | 現状 | スキルでの扱い |
|---|---|---|
| 納税証明書の発行日有効期限 | 一次資料に「発行から◯か月」の規定は**見当たらない**（要件は「申請時点で取得できる直近分」のみ） | 発行日が古くても年度が直近なら❌にしない。年度違いのみ❌ |
| 「直近分」の厳密な起算 | 申請時点で取得できる直近分、としか書かれていない（決算直後の端境期など） | 端境期は⚠️（要確認）に降格 |

| 賞与のみ受給者のR216除外 | 社内ルール確定・事務局未確認のグレー | ⚠️★グレー表記 |
