# 公募要領要点（R215 / R216 関連）

**デジタル化・AI導入補助金2026（旧IT導入補助金）通常枠 公募要領 p.10**（2026-05-31 確認）から、賃金台帳変換に直結する定義を抜粋。
鮮度管理：公募要領が更新されたら本ファイルを差し替える。

> 注：本ツールはデジタル化・AI導入補助金2026 専用。省力化投資補助金 一般型は対象外。

---

## R216「給与支給総額」の定義（デジタル化・AI導入補助金2026 通常枠 公募要領 p.10 原文）

> 1人当たり給与支給総額（非常勤を含む全従業員）とは、給与支給総額を従業員数で除したものをいう。算定対象となる給与等は、給料、賃金、賞与、各種手当（残業手当、休日出勤手当、職務手当、地域手当、家族（扶養）手当、住宅手当）等、**給与所得として課税対象となる経費**を指す。役員報酬、福利厚生費、法定福利費や退職金は除く。

### 重要な含意

- **非課税通勤手当（通勤費の非課税限度内分）は R216 に含めない**
  - 国税庁 No.2585：通勤手当は限度額まで非課税
  - 「給与所得として課税対象」に該当しないため
- **限度超過で課税扱いとなった通勤手当の部分のみ R216 に含める**
- 実務上は賃金台帳の「**課税支給合計**」列を採用するのが最も確実

#### 🔴 判断基準は「通勤手当かどうか」ではなく「課税対象かどうか」

通勤手当を除外するのは**それが非課税だから**。**課税扱いで支給されている通勤手当は R216 に含める**。
「通勤手当だから一律で引く」は誤り（R216 が過小になり決算書の人件費と乖離する）。
実案件で、通勤手当が全額課税扱い（非課税支給額0円）の台帳について「除外すべき」との指摘が出た論点。
判断は台帳の課税/非課税区分に従い、その区分の妥当性は下表で確認する（SKILL.md §3.1.1・verify_transcript.py の T5）。

#### 通勤手当の非課税限度額（国税庁 No.2585・月額）

| 通勤手段 | 非課税限度額 |
|---|---|
| 電車・バス等の交通機関 | 運賃等の実費（最も経済的な経路）で **月15万円**まで |
| マイカー・自転車 片道2km未満 | **0円**（＝全額課税が正しい）|
| 同 2km以上10km未満 | 4,200円 |
| 同 10km以上15km未満 | 7,100円 |
| 同 15km以上25km未満 | 12,900円 |
| 同 25km以上35km未満 | 18,700円 |
| 同 35km以上45km未満 | 24,400円 |
| 同 45km以上55km未満 | 28,000円 |
| 同 55km以上 | 31,600円 |

- 支給額が限度額の**範囲内なのに課税処理されている**場合、会社の源泉処理が誤っている可能性がある
  → 通勤距離・手段を**顧客に確認**（源泉徴収の是正が絡むので Skill 側で勝手に減算しない）。
- 台帳に通勤距離・手段は印字されないため、**機械判定は不可能**。検知して確認を促すのが正しい挙動。

### よくある間違い：通勤費込み「支給合計」を使う

賃金台帳の「支給合計」列（通勤費込み）を R216 に転記してしまうケースが現場で散見されるが、**これは過大計上で公募要領違反**。

担当者によっては「課税給与」シートと「給与総額（通勤費込み）」シートを別々に作って両方提出するケースもあるが、**R216 の転記元は「課税給与」シート一択**。給与総額シートを併走させる実務上の意味はデジタル化・AI導入補助金では無い（申請書に転記する欄もない）。

## R215「従業員数」の算定方法（デジタル化・AI導入補助金2026 通常枠 公募要領 p.10 + 交付申請マニュアル p.86）

### 公募要領原文

> また、**パートタイム従業員については、正社員の就業時間に換算して人数を算出すること。**

### 交付申請マニュアル p.86 算定例

> ※ パートタイム・アルバイト従業員は、正社員の就業時間に換算した人数としてください。
> 例：週20時間勤務（正規雇用は、週40時間労働）の場合
> **従業員数：20 ÷ 40 ＝ 0.5(人)**

### 含意

- **R215 は FTE 換算（小数値）で記入**
- パート・アルバイトは「正社員の就業時間に換算した人数」を計算
- 正社員1人 = 1.0、パート週20h（正社員週40h前提） = 0.5
- ツール側は `STANDARD_ANNUAL_HOURS = 2080h`（週40h × 52週）を正社員基準として実装

### 賃金台帳テンプレへの含意

賃金台帳テンプレートの E列「月間平均時間」と F列「時給」は、パート・アルバイトの FTE 換算に必須。
**パート時間が取れない案件では FTE が正確に算定できない**ため、顧客に再依頼するか、社内で確認する運用が必要。

## 役員の扱い（デジタル化・AI導入補助金2026 通常枠 公募要領 p.10）

> 算定対象となる給与等は…**役員報酬…は除く**。
>
> ※ 従業員を雇用していない法人は、上記の従業員を役員と読み替え、役員報酬と役員数に応じて算出すること。

→ 通常：雇用形態「役員」は R215・R216 から **両方除外**
→ 例外：従業員0名の法人のみ、役員を従業員として読み替えて算出（個人事業主の事業主本人も類似）

---

## 対象者範囲（デジタル化・AI導入補助金2026 通常枠 公募要領 p.10）

> 対象となる従業員は、交付申請時の直近の事業年度及びその算出対象となる各事業年度において、**全月分の給与等の支給を受けた従業員**とする。中途採用や退職等で全月分の給与等の支給を受けていない従業員については、全月分の給与等の支給を受けていない事業年度に限り、算出の対象から除く必要がある。
>
> 当該事業年度において、産前・産後休業、育児休業、介護休業など事業者の福利厚生等により時短勤務を行っている従業員は**算出対象から除くことができる**。

### 含意

- **パート・アルバイトも R215/R216 に算入**（雇用形態が「パート・アルバイト」のままでOK、FTE換算後の小数値で算入）
- **中途入退社者は R215/R216 から除外**
  - ツール側の判定は「12ヶ月すべてが支給>0か」（v0.2.70 最終形）。空欄も 0円も不支給扱いで、1ヶ月でもあれば算定対象外。賞与のみ受給者も除外
  - 現行ツールは 0 を入れても不支給として除外するため誤算入は起きない
  - ただしテンプレ規格としては、不支給月は **空欄** が正（0 は入れない）
- **産休・育休・介護休業による時短勤務者は除外可**（任意）

## 採用すべき列（賃金台帳）

- ◯ **課税給与**（給与所得として課税対象の額）
- ✗ 給与総額（非課税通勤手当を含む場合がある）
- ✗ 差引支給額（社保・税控除後）

---

## 実務式

```
R215 = Σ(対象従業員ごとのFTE換算後人数)
       正社員→1.0、パート→(実労働時間 ÷ 正社員所定労働時間)、中途者・役員除外

R216 = Σ(対象従業員ごとの12ヶ月分の課税給与) + Σ(対象従業員への課税賞与等)
       ただし役員除外、退職金・福利厚生費・法定福利費除外
```

## 未達のペナルティ

計画値未達の場合：
- 達成率に応じた **返還**
- 年平均成長率が0またはマイナスの場合は **全額返還**

→ R216 を低く見積もる（賞与漏れなど）と、計画未達リスクが上がるので注意。
→ R216 を高く見積もる（役員報酬の混入など）と、後年の効果報告で説明不能になる。
→ 過大も過少も避けるため、**変換段階で正確性を担保する** ことがこのスキルの存在意義。
