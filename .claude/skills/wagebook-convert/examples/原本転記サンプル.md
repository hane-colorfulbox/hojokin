# 原本転記シート群のお手本（架空データのみ）

SKILL.md §4.1.2 の「全ページ・全項目・ページ別」転記の完成イメージ。すべて架空の会社・人物・金額。

## ブック全体のシート構成（例：単一PDF 26ページ・9月決算）

```
従業員別明細        ← 算定の正本（ツールが読む）
記入ルール          ← テンプレ由来
原本転記            ← 表紙（ツールは「原本転記*」を読み飛ばす）
原本転記_p1-2       ← 旧書式の1表がp.1-2に続くため結合
原本転記_p3
...
原本転記_p26
```

## データシート例①：行=項目 × 列=従業員（月別一覧型のページ）

シート名 `原本転記_p14`。**印字されている行をすべて**転記する（集計行だけの転記は仕様違反＝FLAG-R）。

| | A | B | C | D |
|---|---|---|---|---|
| 1 | 原本: 賃金台帳.pdf p.14 令和6年10月分（支給日R6.11.25） | | | |
| 2 | 原本印字の合計: 1,013,000 | =SUM(B14:D14) | | |
| 3 | 項目 | サンプル太郎 | サンプル次郎 | サンプル花子 |
| 4 | 出勤日数 | 22 | 21 | 15 |
| 5 | 労働時間 | 176 | 168 | 90 |
| 6 | 基本給 | 350000 | 262000 | 96000 |
| 7 | 技術手当 | | 8000 | |
| 8 | 通勤手当 | | 12000 | 3000 |
| 9 | 時間外手当 | | 25000 | |
| 10 | 課税支給額 | 350000 | 307000 | 99000 |
| 11 | 非課税支給額 | 0 | 0 | 0 |
| 12 | 健康保険 | 17325 | 15330 | |
| 13 | 厚生年金 | 32940 | 28060 | |
| 14 | 総支給額 | 350000 | 307000 | 99000 |

- この例では通勤手当が課税支給額に**含まれて**印字されている（非課税支給額=0）。確認者は `=B10-B8` のような関数で「課税支給額−通勤手当」を出せる——これが全項目転記の狙い
- 行の並び・項目名は**原本のまま**（並べ替え・正規化をしない）。上の例の行構成は説明用で、実物は原本の印字順に従う

## データシート例③：1人1ページの個人台帳型（縦積み）

ページが小さい台帳は1シートに複数ブロックを縦積みしてよい。**各ブロック先頭に出典行**を必ず置く。

```
A1: ▼ 賃金台帳.pdf p.5 サンプル太郎
A2〜: （p.5の行列をそのまま）
（1行空け）
A20: ▼ 賃金台帳.pdf p.6 サンプル次郎
...
```

## やってはいけない例

| ❌ | 理由 |
|---|---|
| 「課税支給額」行だけを月別に並べた転記 | 集計行のみ＝仕様違反。通勤手当等の関数計算ができず、確認者が電卓で引き直す羽目になる（実事故）。verify の FLAG-R が発火 |
| シート名 `pA01_1-2` `10月分` 等の独自名 | ツールのリーダーが賃金表として誤読し R215/R216 を壊す。「原本転記」で始めること（verify が FAIL で検知） |
| 転記だけを別ファイル `○○_賃金台帳_転記.xlsx` に分ける | ファイル名の「賃金台帳」でツールが台帳と誤分類→二重計上の恐れ。同一ブック内に置く |
| 対象事業年度のページだけ転記 | 全ページが標準（前年比較・加点判定に使う）。省略するなら表紙と§9報告に範囲を明記 |
