### この例の読み解き方

**山田太郎**（フル12ヶ月在籍・正社員）：
- G列(1月)=320000 は **2025年1月** の支給額（事業年度の7ヶ月目）
- M列(7月)=320000 は **2024年7月** の支給額（事業年度の1ヶ月目）
- L列(6月)=580000 と R列(12月)=620000 は賞与込み（決算月＝6月、半期＝12月が賞与月）
- S列=36000：年間通勤手当（非課税分のみ）→ ツールが在籍12ヶ月で均等割（月3000円減算）

**鈴木花子**（パート、12ヶ月在籍）：
- E列=80 は月間平均労働時間（→ ツール側で正社員 FTE 換算: 80÷(2080/12)≈0.46人分）
- F列=1100 は時給
- 月額が一定 → 月給制でない時給制

**佐藤次郎**（中途退社、3月で退社）：
- J列(4月)・K列(5月)・L列(6月) は **空欄**（0 ではない）
- つまりカレンダー上の 2025年4〜6月（事業年度の最後3ヶ月）に支給がない
- ツールは「12ヶ月在籍していない」と判定し、**R215/R216 から自動除外**
- 0 を入れると「0円支給だが在籍はしていた」と誤判定されるので絶対 NG

## 2. 月列の配置例（決算月別 Before/After）

落とし穴の具体例。**6月決算の会社** を例にする。
事業年度 = 2024年7月〜2025年6月（決算月=6月）の場合、xlsx の12列に入れる値：

| xlsx 列ラベル | ❌ 間違い（暦年で入れる）| ✅ 正解（事業年度の月をカレンダー位置に）|
|---|---|---|
| G5(1月) | 2024年1月の支給額 | **2025年1月** の支給額 |
| H5(2月) | 2024年2月の支給額 | **2025年2月** の支給額 |
| I5(3月) | 2024年3月の支給額 | **2025年3月** の支給額 |
| J5(4月) | 2024年4月の支給額 | **2025年4月** の支給額 |
| K5(5月) | 2024年5月の支給額 | **2025年5月** の支給額 |
| L5(6月) | 2024年6月の支給額 | **2025年6月** の支給額（決算月＝賞与あり）|
| M5(7月) | 2024年7月の支給額 | **2024年7月** の支給額（事業年度の開始月）|
| N5(8月) | 2024年8月の支給額 | **2024年8月** の支給額 |
| O5(9月) | 2024年9月の支給額 | **2024年9月** の支給額 |
| P5(10月) | 2024年10月の支給額 | **2024年10月** の支給額 |
| Q5(11月) | 2024年11月の支給額 | **2024年11月** の支給額 |
| R5(12月) | 2024年12月の支給額 | **2024年12月** の支給額（賞与あり）|

### 判定ポイント

- L列(6月) が決算月=賞与月の高額になっていれば事業年度の6月。**前年6月の額になっていたら間違い**
- M列(7月) が事業年度の最初の月=2024年7月。**2025年7月（未来）の額になっていたら間違い**（事業年度外）
- 賞与月（6月と12月の2回が典型）の額が他月の2倍以上になっていれば概ね正しい

## 3. 雇用形態ラベルの正規化例

| 元の表記（PDF 原本）| そのまま転記 | 正しい変換 |
|---|---|---|
| 代表取締役 | ❌ R216 算入 | ✅ **役員** |
| 取締役 | ❌ R216 算入 | ✅ **役員** |
| 監査役 | ❌ R216 算入 | ✅ **役員** |
| 理事長・理事（医療法人）| ❌ R216 算入 | ✅ **役員** |
| 現場代理人 / 主任 / 営業 | △（職位名）| ✅ **正社員**（職位は雇用形態ではない）|
| 契約社員 | △ | ✅ **正社員**（フルタイム前提）|
| パート / アルバイト / 非常勤 | △ | ✅ **パート・アルバイト** |

ツール側のロジック（`hojokin/wage_reader.py`）が「役員」文字列の有無で R216 除外判定をしているため、上記の正規化は必須。
