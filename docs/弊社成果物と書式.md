# 弊社成果物と書式

カラフルボックスが デジタル化・AI導入補助金2026（旧IT導入補助金）案件で
**本ツールで「作って・渡す」もの**と、**「使う書式」** の決定版一覧。

> 本資料は **API版ツール（本リポジトリ）の出力仕様** に絞る。
> 制度・必要書類等の業務知識ベース（個人 CC 作業ジャンル）は別フォルダで管理されており、本資料からはリンクしない。

---

## 1. 主成果物（毎案件で必ず作る）

### 1-1. 申請書 Excel
- 出力ファイル名: `{会社名}_{枠}_AI版.xlsx`
- ツール: 本リポジトリの Streamlit（[https://hojokin-uymden838zfglt9uahkapf.streamlit.app](https://hojokin-uymden838zfglt9uahkapf.streamlit.app)）または `run.py`
- 内包シート:
  - **申請内容シート** — 申請者基本情報・役員（最大10名）・財務（直近2期）・経営状況・賃上げ計画
  - **転記シート** — ヒアリング項目のテキスト写し（ポータル入力時の参照用）
  - **生産性指標給与支給総額計算シート** — 売上・粗利・営業利益・経常利益・減価償却・給料手当・賞与・役員報酬・旅費交通費。R215/R216 算出のもと

### 1-2. 給与支給総額計算（申請書 Excel に内包）
- 賃金台帳（直近12ヶ月）から従業員別・月別の給与を集計
- 直近事業年度の総額を **R216** として算出
- 3年計画（R217-R219、年率+3%以上）を自動生成
- 役員は対象外（公募要領準拠）

## 2. サブ成果物（該当案件のみ）

### 2-1. 加点判定（賃上げ加点・項目14/15）— v0.2.39〜 2工程
- **2工程**: ①「加点判定用賃金台帳の作成」で専用台帳 `{会社名}_加点判定用賃金台帳.xlsx` を作る → ②「加点判定」でその台帳から判定。
  - 専用台帳が必要な理由＝加点は「時間換算給与＝基本給÷月間所定労働時間（残業・手当除く）」を暦月固定（令和6年10月〜令和7年9月＋交付申請直近月）で見るため。R215/R216 用の標準賃金台帳では計算できない。
- 出力ファイル名: `{会社名}_加点措置①_結果.xlsx`（通常枠は `補助率引上げ・加点措置①`）、`{会社名}_加点措置②_結果.xlsx`
- ①シートは**申請枠で1枚**（通常枠＝補助率引上げ①用 / インボイス・セキュリティ枠＝加点措置①用）。②は全枠共通。
- 入力に都道府県（会社で1つ）と**交付申請月**が必要（加点②の直近月＝申請月の前月）。役員は判定母数から除外。
- 自動生成台帳は**提出前に人手確認**（基本給・所定労働時間の抽出精度が補助率2/3 を左右）。加点を狙う案件のみ作成。

## 3. 申請枠別テンプレ対応表

| 申請枠 | 法人/個人 | 申請書テンプレ | ヒアリングシート | マッピング名 |
|---|---|---|---|---|
| 通常枠 | 法人 | `【原本_法人】企業名_通常枠_法人2026_v2.xlsx` | `ヒアリングシート2026_通常枠法人.xlsx` | `MAPPING_2026_TSUJO` |
| 通常枠 | 個人事業主 | `【原本_個人】企業名_通常枠_個人2026.xlsx` | `ヒアリングシート2026_通常枠個人.xlsx` | `MAPPING_2026_TSUJO_KOJIN` |
| インボイス枠 | 法人 | `【原本_法人】企業名_インボイス枠_法人2026_v2.xlsx` | `ヒアリングシート2026_インボイス法人.xlsx` | `MAPPING_2026_INVOICE` |
| インボイス枠 | 個人事業主 | `【原本_個人】企業名_インボイス枠_個人2026.xlsx` | `ヒアリングシート2026_インボイス個人.xlsx` | `MAPPING_2026_INVOICE_KOJIN` |

個人事業主版の特徴: 役員セクションなし／資本金=0／決算月=12月／役員数=1 固定／計画年度は暦年（2027〜2029）。

**通常枠は個人事業主も申請できる**（公募要領の補助対象者に法人格の限定はない）。通常枠×個人の
テンプレ・ヒアリング様式は 2026-08-10 に整備した。それ以前の資料に「通常枠は法人のみ」と
書いてあるものがあるが誤り。通常枠×個人だけは他の3つと違い、**通常枠固有ブロック（申請類型・
補助率引上げ・経営状況フル・加点②・労働生産性指標）と個人事業主ブロック（屋号・生年月日・
青色申告決算書・暦年の計画年度）が同居する**点に注意。

## 5. 顧客から回収するもの（ツールの入力データ）

| 入力データ | 形式 | 主な用途 |
|---|---|---|
| ヒアリングシート（記入済）| Excel | 申請者基本情報・役員・賃上げ計画など。申請書の大部分の源泉 |
| 履歴事項全部証明書 | PDF | 法人名・所在地・代表者・設立日・資本金・役員構成 |
| 納税証明書（その1またはその2）| PDF | 提出書類（弊社は読み取りのみ） |
| 決算書（直近2期）| PDF | 売上・粗利・営業利益・経常利益・減価償却・給料手当・賞与・役員報酬・旅費交通費 |
| 賃金台帳（直近12ヶ月）| PDF または Excel | R215/R216 算出のもと。加点判定のもと |

> 各書類の取得要件・有効期限・公募要領上の根拠は、本リポジトリのスコープ外。公募要領で都度確認すること。

## 6. クライアントミーティングで渡すもの（タイミング別）

| タイミング | 渡すもの | 形態 | 目的 |
|---|---|---|---|
| 初回ヒアリング前 | ヒアリングシート | Excel（弊社書式） | 顧客に記入してもらう |
| 申請書 下書き完成後 | 申請書 Excel | Excel（AI生成） | 数値・記述の最終確認 |
| 加点判定 実施時 | 加点措置判定結果 | Excel（AI生成） | 加点可否・対象者の確認 |
| ポータル入力前 | 申請書 Excel の「転記シート」| Excel（AI生成） | 顧客が電子申請ポータルに転記する用 |

> 弊社は **代理申請しない**。最終的にポータルへ入力・送信するのは顧客本人（gBizIDプライム必要）。

## 7. 案件ごとに揃えるべきものチェック（ミーティング前）

ミーティング前に、以下が**全部揃っているか**チェックする：

### 弊社作成物（本ツール出力）
- [ ] 申請書 Excel（`{会社名}_{枠}_AI版.xlsx`）
- [ ] 申請書内の「給与支給総額計算」シートに R216 が算出されている
- [ ] 賃上げ計画（R217-R219）が年率3%以上で入っている（過去交付ありは3.5%）
- [ ] 加点を狙うなら加点措置判定結果

### 顧客側の必要書類（揃っているか確認）
- [ ] 履歴事項全部証明書（取得日から3か月以内）
- [ ] 納税証明書
- [ ] 決算書 2期分
- [ ] 賃金台帳 直近12ヶ月
- [ ] gBizIDプライム 取得済
- [ ] SECURITY ACTION 自己宣言済
- [ ] 見積書（ITツール）

### 加点・要件（公募要領で都度照合）
- [ ] デジwith（IT戦略ナビwith）の実施結果 PDF
- [ ] 成長加速マッチングサービス画面キャプチャ（挑戦課題が「掲載中」）
- [ ] 省力化ナビ ステップ1-4 実施結果 PDF
- [ ] その他加点項目
