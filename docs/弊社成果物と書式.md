# 弊社成果物と書式

## 第7次以降の適用（2026-11-04）

[変更点と使い方](第7次申請_変更点と使い方.md) と [確認待ち事項](第7次申請_確認待ち事項.md)、[公式資料で判断できることと確認の範囲](第7次申請_公式資料で判断できることと確認の範囲.md) を先に確認する。給与0年度目（交付申請日を含む事業年度）は見込み値で入力する（窓口担当が事務局に照会して確認済み）。給与の当期見込みと生産性の前事業年度実績を分け、過去交付歴・表明・対象人数・根拠の未確認をAIで埋めない。効果報告の比較基準は未確定で、今回は申請向け対応まで。

本書の成果物仕様とチェック項目は第7次以降用。第1〜6次（旧回）の訂正・再出力では、旧版の仕様（直近事業年度の実績を基準にした3年計画）を使い、公募回・実申請月・原本版を明示する。過去の検証日・会議発言・実装経緯は当時の記録であり、新要件の裏取りとして流用しない。

カラフルボックスが デジタル化・AI導入補助金2026（旧IT導入補助金）案件で
**本ツールで「作って・渡す」もの**と、**「使う書式」** の決定版一覧。

> 本資料は **API版ツール（本リポジトリ）の出力仕様** に絞る。
> 制度・必要書類等の業務知識ベース（個人 CC 作業ジャンル）は別フォルダで管理されており、本資料からはリンクしない。

## 1. 主成果物（毎案件で必ず作る）

### 1-1. 申請書 Excel
- 出力ファイル名: `{会社名}_{枠}_AI版.xlsx`
- ツール: 本リポジトリの Streamlit（[https://hojokin-uymden838zfglt9uahkapf.streamlit.app](https://hojokin-uymden838zfglt9uahkapf.streamlit.app)）または `run.py`
- 内包シート:
  - **申請内容シート** — 申請者基本情報・役員（最大10名）・財務（直近2期）・経営状況・賃上げ計画
  - **転記シート** — ヒアリング項目のテキスト写し（ポータル入力時の参照用）
  - **生産性指標給与支給総額計算シート** — 売上・粗利・営業利益・経常利益・減価償却・給料手当・賞与・役員報酬・旅費交通費。R215/R216 算出のもと

### 1-2. 給与の計画と実績（申請書 Excel に内包）
- **給与0〜3年度目の計画**: 0年度目＝交付申請日を含む事業年度の見込み、1〜3年度目＝その翌事業年度からの3年。担当者がお客様に確認した総額・人数（FTE）・根拠だけを入れ、「申請前提・給与見込」シートに年度別の値と根拠を出す。AIによる見込みの創作や、年3%などでの自動増額はしない
- **検算**: 1人当たり給与支給総額で「1年後の伸び」と「3年間の年平均の伸び」を出し、区分に応じた率（必須の区分は3%以上、過去交付ありは3.5%以上）に届いているかを確認する
- **前事業年度の実績（参考）**: 賃金台帳（前事業年度の12か月分）から従業員別・月別の給与を集計し、総額を **R216** として算出する。第7次以降は見込みを考える参考で、給与0年度目には流用しない
- 役員は対象外（公募要領準拠。従業員を雇用していない法人は役員で読み替える例外あり）
- 第1〜6次（旧回）の訂正・再出力だけは、旧方式（直近事業年度の R216 を基準に R217-R219 の3年計画を作る）を使う

## 2. サブ成果物（該当案件のみ）

### 2-1. 加点判定（賃上げ加点。通常枠は項目14/15、インボイス対応類型は11/12）— v0.2.39〜 2工程
- **2工程**: ①「加点判定用賃金台帳の作成」で専用台帳 `{会社名}_加点判定用賃金台帳.xlsx` を作る → ②「加点判定」でその台帳から判定。
  - 専用台帳が必要な理由＝加点は各月の「時間換算給与」を暦月固定（令和7年10月〜令和8年9月＋交付申請直近月）で見るため。R215/R216 用の標準賃金台帳では計算できない。時間換算給与は厚生労働省「最低賃金額以上かどうかを確認する方法」で計算する（臨時の賃金・賞与・割増賃金・精皆勤手当・通勤手当・家族手当は除き、職務手当など通常の手当は含める）。台帳は1つの「基本給」の値から計算するため、通常の手当がある人は手で確認する。
- 出力ファイル名: `{会社名}_加点措置①_結果.xlsx`（通常枠は `補助率引上げ・加点措置①`）、`{会社名}_加点措置②_結果.xlsx`
- ①シートは**申請枠で1枚**（通常枠＝補助率引上げ①用 / インボイス・セキュリティ枠＝加点措置①用）。②は全枠共通。
- 入力に都道府県（会社で1つ）と**交付申請月**が必要（加点②の直近月＝申請月の前月）。役員は判定母数から除外。
- 自動生成台帳は**提出前に人手確認**（基本給・所定労働時間の抽出精度が補助率2/3 を左右）。加点を狙う案件のみ作成。

## 5. 顧客から回収するもの（ツールの入力データ）

| 入力データ | 形式 | 主な用途 |
|---|---|---|
| ヒアリングシート（記入済）| Excel | 申請者基本情報・役員・賃上げ計画など。申請書の大部分の源泉 |
| 履歴事項全部証明書 | PDF | 法人名・所在地・代表者・設立日・資本金・役員構成 |
| 納税証明書（その1またはその2）| PDF | 提出書類（弊社は読み取りのみ） |
| 決算書（直近2期）| PDF | 売上・粗利・営業利益・経常利益・減価償却・給料手当・賞与・役員報酬・旅費交通費。通常枠の労働生産性の基準は前事業年度の実績 |
| 給与0〜3年度目の見込み・計画 | ヒアリング等 | 0年度目（交付申請日を含む事業年度）の見込みと1〜3年度目の計画。総額・人数（FTE）・根拠をお客様に確認する |
| 労働生産性1〜3年度目の計画（通常枠）| ヒアリング等 | 営業利益・人件費・減価償却費・年間総労働時間・根拠 |
| 賃金台帳 | PDF または Excel | 用途ごとに必要な年月をすべて覆う分を回収する（前事業年度の実績＝R215/R216、0年度目見込みの根拠、加点①の令和7年10月〜令和8年9月、加点②の令和8年6月と申請月の前月）。冊数は固定しない |

> 各書類の取得要件・有効期限・公募要領上の根拠は、本リポジトリのスコープ外。公募要領で都度確認すること。

## 6. クライアントミーティングで渡すもの（タイミング別）

| タイミング | 渡すもの | 形態 | 目的 |
|---|---|---|---|
| 初回ヒアリング前 | ヒアリングシート | Excel（弊社書式） | 顧客に記入してもらう |
| 申請書 下書き完成後 | 申請書 Excel | Excel（AI生成） | 数値・記述の最終確認 |
| 加点判定 実施時 | 加点措置判定結果 | Excel（AI生成） | 加点可否・対象者の確認 |

> 弊社は **代理申請しない**。最終的にポータルへ入力・送信するのは顧客本人（gBizIDプライム必要）。

## 7. 案件ごとに揃えるべきものチェック（ミーティング前）

ミーティング前に、以下が**全部揃っているか**チェックする：

### 弊社作成物（本ツール出力）
- [ ] 申請書 Excel（`{会社名}_{枠}_AI版.xlsx`）
- [ ] 給与0年度目（交付申請日を含む事業年度）の見込みと1〜3年度目の計画が、お客様に確認した総額・人数（FTE）・根拠で入っている（前事業年度の実績を0年度目に流用していない）
- [ ] 1人当たり給与支給総額で、1年後の伸びと3年間の年平均の伸びがどちらも区分に応じた率に届いている（必須の区分は3%以上、IT導入補助金2022〜2025の交付決定ありは3.5%以上。必須でない区分は任意加点を希望する場合だけ年平均3%以上）
- [ ] 必須の区分では、1年後と年平均の両方を含む賃上げ計画を従業員に表明した日付・方法を確認している
- [ ] 通常枠は、労働生産性の基準（前事業年度の実績）と1〜3年度目の確認済み計画が入っている
- [ ] 申請書内の「給与支給総額計算」シートの R216（前事業年度の実績）は参考値として確認した
- [ ] 加点を狙うなら加点措置判定結果

### 顧客側の必要書類（揃っているか確認）
- [ ] 履歴事項全部証明書（取得日から3か月以内）
- [ ] 納税証明書
- [ ] 決算書 2期分
- [ ] 賃金台帳（用途ごとに必要な年月をすべて覆う分。冊数は固定しない）
- [ ] gBizIDプライム 取得済
- [ ] SECURITY ACTION 自己宣言済
- [ ] 見積書（ITツール）

### 加点・要件（公募要領で都度照合）
- [ ] デジwith（IT戦略ナビwith）の実施結果 PDF
- [ ] 通常枠: IT経営サポートセンターの利用（2026/8/1以降の申込、申込名義・住所・法人番号が申請と一致、交付申請日以前かつ締切日の前月末日までの利用）。IT戦略ナビwithと同じ項目のため、両方使っても加点は1つ
- [ ] 通常枠: デジタル化セカンドオピニオンは、確認者との面談が完了してから交付申請する（加点の条件。通常枠公募要領 第7回〜版 印刷p.23 項目4）
- [ ] 成長加速マッチングサービス画面キャプチャ（挑戦課題が「掲載中」）
- [ ] 省力化ナビ ステップ1-4 実施結果 PDF
- [ ] その他加点項目
