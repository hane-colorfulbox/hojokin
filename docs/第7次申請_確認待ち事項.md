# 第7次申請：確認待ち事項（個別確認・社内調整・保留）

対象読者：申請担当者・窓口担当・管理者。公式資料で判断できることと、案件ごとに確認すること、保留していることを分ける管理票です。

更新日：2026-11-06。第7回公募（以下「7次」）以降の申請用です。

## 公式の定義を当てはめること（事務局に聞き直さない）

- 対象従業員、全月支給者の判定、途中入退社、パート等の換算、要領に書かれた時短勤務者の除外、従業員を雇用しない法人の役員への読替え。
- 給与の基本的な算入範囲と、通常の手当の例示。
- 給与と生産性の基準年度・計画年度、過去交付歴別の率（補助金名の年度で判定）、任意加点の＋30円／＋50円の区分。
- 加点①の期間・上限（令和8年度改定の地域別最賃未満）・人数割合・月数、加点②の基準月・直近月・55円、加点①②の母数（各月の常時使用する従業員）と時間換算給与の計算方法（厚生労働省の確認方法）。

根拠は [公式資料で判断できることと確認の範囲](第7次申請_公式資料で判断できることと確認の範囲.md) にあります。給与0年度目を見込み値で入力することは、窓口担当が事務局に照会して確認済みです。

## 社内で調整すること

| 項目 | 今回の扱い |
|---|---|
| 事務局照会の記録 | 0年度目を見込み値とする照会について、照会日と回答の要旨を窓口担当の記録として残す。顧客や他の支援事業者に聞かれたときに示せるようにする |
| 回収票・ヒアリング | 回収案は用意済み。調整済みの票があれば共有してもらい、重複を避ける。制度の未回答事項として事務局へ聞かない |
| 通勤手当の全額控除方式 | 公表された課税給与の定義と違うことを明示する。課税される通勤手当の算入は一般定義からの解釈。新規申請では方式を記録し、旧成果物は保存する |
| Drive原本・本番ツール・プラグインの配布 | 置き場所・リンク・権限・反映内容を管理者が確認する。制度の照会とは別の工程。push・送信は自動では行わない |

## 個別案件で事実が足りない場合だけ確認すること

| 足りないこと | 確認する資料・事実 | 確認できるまでの扱い |
|---|---|---|
| 見込み値の中身 | 対象年度の支給見込み、対象者・人数、実績月と予算、賞与・昇給などの根拠 | 数値をAIで補わず、その提出値の確定を保留 |
| 前事業年度の決算が未確定 | 9〜11月決算の会社が11〜12月に申請する場合など、前事業年度は終わっているが決算が確定していないとき | 個別確認。1期前の確定済みの実績を自動で使わない（マニュアルp.88の「前事業年度」とFAQ No.34・36の「直近決算期」で記述が分かれている） |
| 個人事業主の給与の算入範囲 | マニュアルp.86・89・91は「代表者の確定申告書の事業所得欄＋賃金台帳（従業員分）」を根拠資料に挙げている。FAQ No.33は専従者を従業員数に含めないとしている。FAQ No.41・42は従業員がいない場合の計画の扱い | 事業主本人の所得・専従者給与をどこまで含めるか（特に従業員がいない場合）は案件ごとに確認し、確定するまで計画値を確定しない |
| 加点の時間換算給与に入る賃金 | 職務手当などの手当、歩合給・出来高給の有無と額、基本給に含まれる固定残業代（みなし残業代）の額（厚生労働省の確認方法で含める賃金・除く賃金） | 7次以降版の加点用台帳のAH〜AT列（時間換算の対象月額）に、その月の賃金から6種を除いた額を入れ、含めた手当の名目を原本で確認する。歩合給・出来高給がある人は、その月の総労働時間を確認できるまでその月を空欄（未確定）にする。対象月額が基本給より少ない月は、その理由を雇用契約・賃金規程で確かめて記録する |
| 加点の母数 | 各月に常時使用する従業員か（日雇い、2か月以内の期間雇用、季節的業務で4か月以内、試用期間中で14日以内の人は入らない） | 分からない人は母数に残し、判定を未確定にする |
| 支給月・勤務時間 | 入退社・休業・勤務などの事実、就業時間、公式の例外に当たるか | 定義は聞き直さず、足りない事実だけ確認 |
| 課税区分・内訳 | 給与明細・台帳・支給内訳。給与と加点で使う賃金の定義の違い | 内訳が分からない金額だけ確認 |
| 生産性の実績・計画 | 前事業年度の実績と、申請翌事業年度から3年の計画の根拠 | 年度・時間・数値が未確認の申請書を確定しない |
| 所在地・月の途中の改定 | 実際の勤務地、主たる事業所の選び方、計算期間、行政が公表した法定発効日 | 一律の県や改定日を仮定しない。複数県があること自体は、制度の未確定とは扱わない |
| 元の申請の扱い | 第1〜6次の申請を直すのか、7次で新しく申請するのか、公募回、申請ID | 元の成果物を保存し、使う版を決める |
| 当てはめきれない例外 | 無給休職、短期決算、設立初年度などの具体的な事実と該当条項 | 一般的な質問に広げず、その案件の疑問点にしぼる |

## 効果報告の比較基準は今回は保留

申請時の見込みを後年の効果報告の基準にするか、確定した実績を使うかは、公式資料に記載がありません（2026/11/5改訂の後年手続きマニュアルにもありません）。今回は申請に向けた作業を進め、同じ質問を繰り返しません。申請時の見込み・対象人数・根拠・版を、生成された申請書の「申請前提・給与見込」シートと案件フォルダに残し、新しい公式案内が出た段階で対応します。

## 問い合わせが必要になった場合

公募回・枠・年度、具体的な事実、参照した公式の条項、それでも残る疑問点、回答で確定できる出力を記録してから、窓口担当に相談します。公式の定義の再確認や、回答済みの論点をまとめて依頼しません。窓口・事務局への連絡は自動では行いません。
