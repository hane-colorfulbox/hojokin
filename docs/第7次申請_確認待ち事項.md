# 第7次以降の申請：確認待ち事項

更新日：2026-11-04。確認待ちだけを列挙し、回答済みの論点を再度未確認に戻さないための管理票。

## 確認済み

- 給与の0年度目は、交付申請日の属する事業年度。
- 0年度目として入力する数値は見込み値。窓口担当の事務局照会回答をユーザーが提示済み。
- 労働生産性は前事業年度が基準で、給与0年度目と分ける。
- 第7次の加点①は2025/10〜2026/9、加点②は2026/6から実申請前月まで55円以上。

生産性0年度目＝前事業年度実績、1年度目＝申請当年度、2年度目＝翌事業年度、3年度目＝翌々事業年度。給与0年度目＝申請当年度見込み、1年度目＝翌事業年度であり、同じ年度番号でも生産性と給与は1年ずれる。

## 個別案件で確認が必要なこと

| 確認事項 | 確認するもの | 未回答時の扱い |
|---|---|---|
| 0年度目の対象従業員とFTEの細部 | 全月支給者の判定年度、見込み人数、休業・入退社・役員のみ法人・個人事業主等の対象範囲 | 対象人数や給与を推定で確定せず、該当計画の確定出力を保留 |
| 見込みの根拠と回収項目 | 期中実績、残期間予算、賞与・昇給等の根拠、担当確認。資料・ヒアリング追加は窓口側の調整結果 | 回収票は案として用意し、既存の調整に合わせて最終化。AIが不足月を補完しない |
| 生産性1〜3年度目の計画（通常枠） | 前事業年度実績と、生産性1年度目＝申請当年度から3年度目＝翌々事業年度まで3年間の営業利益・人件費・減価償却費・総労働時間、各年の根拠・確認状態。3%／4%の対象となる過去指定枠の交付歴 | 給与見込みと分けて回収。通常枠150万円未満・任意賃上げなしでも省略せず、未確認なら該当申請書の提出用確定出力を止める。旧B42のOK表示を確認の代わりにしない |
| 賃金の算入範囲 | 課税通勤手当、本給と通常手当、法定最賃用の賃金と様式入力の関係 | 従来方式を無断変更せず、疑義がある数値だけ個別確認。「基準が下がるから安全」と断定しない |
| 月途中改定・複数所在地 | 賃金計算期間、実勤務地・派遣先、発効日、対象事業場 | 単一県・月平均の仮定で適合／違反や加点を確定しない |
| 元申請の訂正と再申請 | 元申請ID、公募回、不備訂正か不採択後の新規申請か | 元成果物を保存。適用版に疑義があるときは提出用確定を保留 |
| 短期決算・設立初年度・決算直後 | 給与の対象年数、まだ確定していない前期決算、生産性の入力根拠 | 生産性の年換算指示を給与へ流用しない。未確定資料を実績扱いしない |
| 公式様式の表示不整合 | ②の最賃マスタ等と、事務局の訂正版・取扱い | 原本は保持。氏名等の通常入力欄の清掃と、マスタ・数式の改変を分ける |

## 効果報告の比較基準は今回は保留

0年度目に申請した見込み値を後年の効果報告でそのまま基準にするか、確定した実績と比較するかは未確定です。事務局も現時点で明確に回答できていないとの共有があります。

この点の回答待ちで、確定済みの申請向け修正を止めません。申請時の計画値・後日判明した実績値・対象人数・根拠・適用版を別々に保存し、新しい公式案内が出た段階で対応します。今すぐ同じ質問を事務局へ繰り返し照会する必要はありません。

## 担当者へ渡す確認メモの形式

- 対象：公募回・申請予定月・枠・法人／個人（顧客実名・従業員名・給与額を公開用資料に書かない）。
- どの入力または判断が未確定か。
- 現在の根拠、確認済みの範囲、回答が必要な箇所。
- 回答でどの出力を確定できるか。
- 回答日・確認先・回答内容と、反映した版。
