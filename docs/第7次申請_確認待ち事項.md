# 第7次申請：個別確認・社内調整・保留事項

更新日：2026-11-04（公式資料の再照合後）。公式で定義済みのことを再質問しないための管理票です。

## 公式資料で判断できるため再照会しないこと

- 対象従業員、全月支給者の判定、途中入退社、パート等の換算、要領に記載された時短勤務者の除外、従業員を雇用しない法人の役員読替え。
- 給与の基本的な算入範囲と通常手当の例示。
- 給与と生産性の基準・計画年度、過去交付歴別の率、任意加点の＋30円／＋50円の区分。
- 加点①の期間・人数割合・月数、加点②の基準月・直近月・55円。

根拠は [公式資料で判断できることと確認の範囲](第7次申請_公式資料で判断できることと確認の範囲.md) を参照します。給与0年度目が見込み値である点も、共有済みの事務局照会回答で確認済みです。

## 社内で調整すること

| 項目 | 今回の扱い |
|---|---|
| 回収票・ヒアリング | 回収案は用意済み。既存の調整済み票があれば共有してもらい重複を避ける。制度の未回答事項として事務局へ聞かない |
| 通勤手当全額控除の旧方式 | 公表された課税給与定義との不一致を明示。課税通勤の算入は一般定義からの解釈。旧方式を新規申請へ無条件に流用せず、旧成果物は保全 |
| Drive原本・本番・配布 | 配置先・リンク・権限・反映内容を管理者が確認。制度照会とは別工程。push・送信は自動実行しない |

## 個別案件で事実が不足した場合だけ確認すること

| 不足していること | 確認する資料・事実 | 未確認時の扱い |
|---|---|---|
| 見込み値の中身 | 対象年度の支給見込み、対象者・人数、実績月と予算、賞与・昇給等の根拠 | 数値をAIで補完せず該当提出値の確定を保留 |
| 支給月・勤務時間 | 入退社・休業・勤務等の事実、就業時間、公式例外への該当 | 定義を聞き直さず不足事実だけ確認 |
| 課税区分・内訳 | 給与明細・台帳・支給内訳。給与と加点で使う賃金定義の違い | 内訳不明の金額だけ確認 |
| 生産性の実績・計画 | 前期実績と申請翌事業年度から3年の計画根拠 | 年度・時間・数値が未確認の申請書を確定しない |
| 所在地・月途中改定 | 実勤務地、主たる事業所の選定、計算期間、行政公表の法定発効日 | 一律の県や改定日を仮定しない。複数県自体を制度未確定とはしない |
| 元申請の扱い | 訂正か新規再申請か、公募回、申請ID | 元成果物を保全し適用版を特定 |
| 当てはめきれない例外 | 無給休職、短期決算、設立初年度等の具体的な事実と該当条項 | 一般的質問に広げず、その案件の疑義に限定 |

## 効果報告の比較基準は今回は保留

申請時の見込みを後年報告の基準にするか、確定実績を使うかは、窓口共有では事務局も未確定です。今回は申請向け作業を進め、同じ質問を繰り返しません。申請時の見込み・対象人数・根拠・版を保存し、新しい公式案内が出た段階で対応します。

## 問い合わせが必要になった場合

公募回・枠・年度、具体的事実、参照した公式条項、それでも残る疑義、回答で確定できる出力だけを記録します。公式定義の再確認や回答済み論点をまとめて依頼しません。窓口・事務局への連絡は自動で行いません。

現時点で一般的な申請ルールの一括再照会を必須とする項目はありません。
