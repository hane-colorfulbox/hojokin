# 外部クライアント向け 賃金台帳集計プロンプト

人力フォーマット（申請フォーマット）の「給与支給総額」「従業員数」欄を埋めるための数字を、
各社が使っている任意の AI（ChatGPT / Gemini / Claude 等）で賃金台帳から出すための指示文。

- 用途: 自動化ツールを提供していない外部クライアント（コンサル経由の代理申請者等）への共有用
- 共有先: 村上さん・坂平さん経由でクライアントに渡す
- 注意: AI の精度はツールによって差があるため、**出力はあくまで下書き。必ず賃金台帳の原本と突合してから申請フォーマットに転記する**こと

---

## 使い方（クライアントへの案内文）

1. お使いの AI チャット（ChatGPT / Gemini / Claude など、ファイル添付ができるもの）を開く
2. 賃金台帳のファイル（Excel または PDF）を添付する
3. 下のプロンプトをコピーして貼り付け、●●部分（決算月）だけ書き換えて送信する
4. 出てきた表と合計値を、**必ず賃金台帳の原本と照合**してから申請フォーマットに転記する

---

## プロンプト本文（ここからコピー）

```
あなたはデジタル化・AI導入補助金の申請書類作成を手伝う経理アシスタントです。
添付した賃金台帳から、従業員ごとの給与一覧表と「給与支給総額」を作成してください。

【前提】
- 当社の決算月は ●● 月です（例: 3月決算 → 3月）。
- 集計対象は「直近の事業年度の12ヶ月」です（決算月の翌月から決算月まで。暦年の1〜12月ではありません）。
  例: 3月決算なら 前年4月〜当年3月 の12ヶ月。

【作業手順】
1. 賃金台帳に載っている全員について、次の一覧表を作ってください。
   | No | 氏名 | 雇用形態 | 対象12ヶ月の月別支給額（12列） | 年間合計 | 年間通勤手当 | 年間賞与 | 判定 |
2. 月別支給額は「課税対象の支給合計」を使ってください。
   - 含める: 基本給、残業手当、役職手当、家族手当など課税される手当
   - 含めない: 社会保険料や税金を引いた後の「差引支給額（手取り）」
   - **通勤手当は、月別支給額に含まれていてもそのまま入れてください（そちらで差し引かない）。**
     代わりに「年間通勤手当」列に年間合計を書いてください（課税・非課税の区別は不要です）。
     差し引きはこちらで行います（そちらで引くと元の金額との検算ができなくなるためです）。
   - 通勤手当が「諸手当」に合算されていて金額が分からない場合は、「年間通勤手当」列に
     **「内訳不明」**と書いてください（推測で埋めない）。
3. 賞与は月別に混ぜず、「年間賞与」列に年間合計で記載してください。
4. 「判定」列には、次のルールで「対象」か「対象外（理由）」を書いてください。
   - 役員（取締役・監査役など）→ 対象外（役員）
   - 対象12ヶ月のうち給与の支給がない月がある人（年度途中の入社・退職など）→ 対象外（全月支給なし）
   - 対象12ヶ月の支給額がすべて0円の人 → 対象外（支給0円）
   - それ以外 → 対象
5. 最後に次の3つを計算してください。
   A. 給与支給総額 = 「対象」の人の（年間合計 − 年間通勤手当 ＋ 年間賞与）の総和
      （年間通勤手当が「内訳不明」の人は引かずに計算し、その旨を明記してください）
   B. 対象の従業員数 = 「対象」の人数（正社員は1人。パート・アルバイトは
      「月平均労働時間 ÷ 173.3時間」で小数換算。労働時間が台帳から読めない場合は
      その人の名前を挙げて「労働時間の確認が必要」と書く）
   C. 検算 = 台帳に合計欄があれば、あなたが集計した全員分の総和と一致するか確認し、
      一致しない場合は差額と考えられる原因を書く

【守ってほしいこと】
- 数字を推測で埋めないでください。読み取れないセルは「読み取り不可」と明記してください。
- 台帳に複数年度が含まれる場合は、どの12ヶ月を採用したかを最初に宣言してください。
- 雇用形態が台帳から判断できない人は、勝手に決めずに「要確認」としてください。
- 最後に「人間が確認すべきポイント」（読み取りに自信がない箇所、対象/対象外の判断が
  微妙な人など）を箇条書きでまとめてください。
```

## 渡すときの補足（社内メモ）

- A が申請フォーマットの「給与支給総額」、B が「従業員数」に対応する（フォーマット上の行番号はクライアント側資料による）
- 173.3時間 = 週40時間 × 52週 ÷ 12ヶ月（公募要領のFTE換算の標準値）
- 0円除外・役員除外・全月在籍ルールは社内ツール（v0.2.66）と同じ基準に揃えてある
- クライアントの AI が表をうまく読めない場合は、賃金台帳を Excel 形式でもらい直すよう案内する
