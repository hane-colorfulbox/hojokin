# 第7次申請：担当者向け要点

対象読者：申請担当者（申請書づくり・加点判定を担当する社員）。第7次の資料は、まずこの要点から読みます。

作成日：2026-11-05。デジタル化・AI導入補助金2026の第7回公募（以下「7次」）以降の申請に使います。第1〜6次で出した申請を訂正するときは、旧回の資料と様式を使います。

## 1. 7次の日程

- 交付申請の締切：2026年12月1日（火）17:00
- 交付決定：2027年1月19日（予定）
- 事業実施期間・実績報告の期限：2027年7月30日（金）17:00（予定）

申請月は締切月とは限りません。加点②の「直近月」は、実際に申請する月の前月です（11月に申請すれば10月、12月1日に申請すれば11月）。

## 2. ツールとプラグインの対応状況

7次の申請書と加点判定は、7次に対応した版で作ります。

| 使うもの | 7次対応版の見分け方 | 確認のしかた |
|---|---|---|
| 書類作成ツール（Streamlit） | フッターの版が v0.2.100 以上 | 画面のいちばん下にある「補助金書類自動作成ツール v0.2.○○」の数字 |
| 組織プラグイン hojokin（スキル4本） | 版の日付が 2026.11.06 以降 | hojokin-guide に「プラグインの版を確認して」と頼む。「hojokin 版 2026.11.06-…」のように表示される |
| 申請書の原本・ヒアリングシート | 「第7次以降用」と表示されている版 | 原本はシート上の版表示を見る。Driveの原本は原本管理担当が7次版に更新してから案内する。案内があるまで、Driveの旧原本・旧ヒアリングで7次の案件を作らず、顧客にも送らない |

これより前の版（ツール v0.2.97・v0.2.99 など、プラグイン 2026.09.30 版・2026.11.05 版など）は7次に対応していません。v0.2.99 と 2026.11.05 版は、加点用台帳の時間換算の対象月額の列（AH〜AT列）を読まず、加点①を多く判定するおそれがあります。7次の申請書・加点判定はそれで作らず、管理者に連絡して7次対応版の反映を待ちます。

## 3. 7次で変わる点

公式の告知（2026年10月9日）が挙げた3点に、給与の基準年度を加えた4点です。

| 項目 | 7次以降 | 第1〜6次（旧回の訂正用） |
|---|---|---|
| 加点①・通常枠の補助率引上げ（1/2→2/3） | 2025年10月〜2026年9月のうち任意の3か月で、「その月の地域別最低賃金以上〜令和8年度改定の地域別最低賃金未満」の従業員が全従業員の30%以上。3か月は連続でなくてよい（東京の例：1,226円以上1,280円未満） | 2024年10月〜2025年9月。上限は令和7年度改定の地域別最低賃金 |
| 加点② | 申請月の前月の事業場内最低賃金が、2026年6月の事業場内最低賃金＋55円以上 | 2025年7月比で＋63円以上 |
| 給与の1年後要件（新設） | 賃上げが必須の申請は、1年後に1人当たり給与支給総額を3%以上（IT導入補助金2022〜2025の交付決定ありは3.5%）伸ばす計画。年平均も同じ率 | 1年後要件はなく、年平均の要件だけ |
| 給与の基準（0年度目） | 交付申請日の属する事業年度。まだ終わっていない期なので見込み値で入力する（窓口担当が事務局に照会して確認） | 直近事業年度（前期）の賃金台帳の実績 |

労働生産性（通常枠）の基準は、前事業年度の実績です。給与と生産性で基準の年度は違いますが、計画の1〜3年度目はどちらも申請日の翌事業年度からの3年です。

## 4. 今日やること

1. 案件ごとに、実際に申請する日を決める。申請月が変われば加点②の直近月も変わる。
2. ツールとプラグインの版を確認する（2.の表）。
3. 顧客に、5.の年月をすべて含む賃金台帳・資料を依頼する。「直近2期分」のような冊数ではなく年月で依頼する。
4. 過去の交付決定を、補助金名の年度（IT導入補助金2022〜2025）と枠で確認する。交付決定日の年で判断しない。
5. 給与0年度目の見込みと1〜3年度目の計画を顧客と決め、根拠（当期の実績月、残りの月の見込み、賞与・昇給の予定）を案件フォルダに残す。
6. 賃上げが必須の申請では、1年後と年平均の両方を含む賃上げ計画を交付申請までに従業員へ表明してもらい、実施日と方法を記録する。
7. セカンドオピニオンの加点を使う場合は、確認者との面談を終えてから交付申請を出す。

## 5. 回収する年月（2026年11月に申請する12月決算の会社の例）

| 用途 | 必要な年月 | 主な中身 |
|---|---|---|
| 加点①・補助率引上げ | 2025年10月〜2026年9月の全月 | 各月の常時使用する従業員、基本給、時間換算給与に入る手当（加点用台帳のAH〜AT列に基本給との合計を入れる）、所定労働時間 |
| 加点② | 2026年6月と、申請月の前月（2026年10月） | 加点①と同じ |
| 給与0年度目 | 2026年1月から申請時点までの実績と、残りの月の見込み | 給与・賞与の実績と予定、対象人数 |
| 労働生産性（通常枠） | 前事業年度（2025年1月〜12月） | 決算書（営業利益・人件費・減価償却費）、総労働時間 |

## 6. ツールが止まる場合と対処

- 通常枠で、賃金台帳の月の見出しに年が入っていない（「1月」「2月」だけ）→ 見出しを「令和7年1月」「2025年1月」のように年付きにした台帳で、もう一度実行する。
- 前事業年度の労働時間が、一部の人・月の分しかない → 足りない月の労働時間を回収する。役員以外は全員、月間平均時間（E列）か月別の時間を入れる（正社員も空欄にしない）。
- 前事業年度の途中に入社・退社した人がいて、その人の入社前・退職後の月が空欄 → 名簿・入退社日などで在籍していないと確認できた月の欄に「非在籍」と書いて、もう一度実行する。非在籍の月は総労働時間から除かれる。空欄・0円の月は非在籍とみなさない。休職など在籍していて給与のない月は空欄のまま止まるので、管理者に相談して個別に対応する。
- 「非在籍」と書いた月に給与や労働時間がある → どちらが正しいかを原本で確かめて直す。
- 給与0〜3年度目の計画、交付歴、表明が未確認 → 顧客に確認して入力する。
- 画面と加点用台帳で、申請月・事業場の所在地が違う → 正しい値にそろえる。
- 加点用台帳（7次以降版）の時間換算の対象月額（AH〜AT列）が空欄の月がある → 加点の判定は「未確定」になる。基本給＋職務手当などの通常の手当を入れる（通常の手当がない人も基本給と同じ額）。基本給はF〜R列に入れ、様式の【基本給】欄はツールがそこから作る。
