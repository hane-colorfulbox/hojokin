# 補助金申請書類 作成マニュアル

## このマニュアルについて

Claude Code（VSCode拡張機能）を使って、デジタル化・AI導入補助金の申請書類を半自動で作成する手順書です。
Claude Codeに詳しくなくても、このマニュアルの通りにやれば大丈夫です。

本書は**ローカル（手元の Claude Code）で作る場合**の手順です。ブラウザだけで速く済ませたい場合は Streamlit ツールを使います（ツールの中身は [引き継ぎ/03 ツールの仕組みと使い方](../引き継ぎ/03_ツールの仕組みと使い方.md)、どちらを使うかの判断は [引き継ぎ/07 ツールとローカルの役割分担](../引き継ぎ/07_ツールとローカルの役割分担.md)）。
なお、賃金台帳PDFの変換は `wagebook-convert`、加点判定は `katen-judge` という専用スキルがローカルの正式経路です。本書の §6 はツールで加点判定をやる場合の手順です。

---

## 1. 事前準備（初回のみ）

### 1-1. VSCodeでClaude Codeを使えるようにする

1. VSCodeを開く
2. 左のアイコンバーから拡張機能（四角いマーク）をクリック
3. 検索欄に「Claude Code」と入力
4. 「Claude Code」をインストール
5. VSCode左下にClaudeのアイコンが出たらOK

### 1-2. フォルダ構成

作業フォルダは以下の場所に統一してください:

```
c:/Users/[自分のユーザー名]/projects/カラフルボックス/補助金/
├── ツール/                        ← テンプレート置き場（触らない）
│   ├── 【原本_法人】企業名_通常枠_法人2026_v2.xlsx
│   ├── 【原本_個人】企業名_通常枠_個人2026.xlsx
│   ├── 【原本_法人】企業名_インボイス枠_法人2026_v2.xlsx
│   └── 【原本_個人】企業名_インボイス枠_個人2026.xlsx
│
├── [顧客名]資料/                  ← 顧客ごとにフォルダを作る
│   ├── ヒアリングシート_xxx.xlsx
│   ├── 履歴事項全部証明書_xxx.pdf
│   ├── 納税証明書_xxx.pdf
│   ├── 損益計算書_第1期_xxx.pdf
│   ├── 損益計算書_第2期_xxx.pdf
│   ├── 見積書_xxx.xlsx
│   ├── 給与データ_xxx/            ← 月次の支給控除一覧PDF
│   │   ├── 3月度支給控除一覧.pdf
│   │   ├── 4月度支給控除一覧.pdf
│   │   └── ...
│   └── 提出資料/
│       ├── 賃金台帳.pdf
│       └── 賃金状況報告シート.xlsx
```

**ファイル名のルール:**
- ファイル名にはなるべく顧客名を入れる（Claudeがどの会社の資料か判別できるように）
- ファイル名は日本語でOK

## 2. 申請書作成（タスク1）

ヒアリングシート・登記簿・決算書などから、申請書テンプレートに自動転記します。

### 手順

1. **VSCodeを開く**
2. **Claude Codeのチャット欄を開く**（左下のClaudeアイコンをクリック）
3. **下のプロンプトをコピーして、★の部分だけ書き換えて送信**

---

### コピペ用プロンプト（申請書作成）

```
補助金の申請書類を作成してください。

■ 顧客名: ★顧客名をここに入れる★
■ 申請枠: ★「通常枠」か「インボイス枠」を入れる★
■ 法人 / 個人事業主: ★どちらかを入れる★
■ 資料フォルダ: c:/Users/★自分のユーザー名★/projects/カラフルボックス/補助金/★顧客名★資料/
■ テンプレート: 下表から、申請枠 × 法人格 の1つを選んでフルパスで指定する
   通常枠×法人     … 補助金/ツール/【原本_法人】企業名_通常枠_法人2026_v2.xlsx
   通常枠×個人     … 補助金/ツール/【原本_個人】企業名_通常枠_個人2026.xlsx
   インボイス枠×法人 … 補助金/ツール/【原本_法人】企業名_インボイス枠_法人2026_v2.xlsx
   インボイス枠×個人 … 補助金/ツール/【原本_個人】企業名_インボイス枠_個人2026.xlsx
   ※法人用テンプレで個人事業主の申請書を作ると、役員セクション・資本金・決算月・計画年度が
     すべて食い違う。しかも空欄数には現れないので気づけない。ここは必ず合わせる

■ 作業内容:
1. 資料フォルダの中身を確認してファイル一覧を出す
2. テンプレートExcelのコピーを作成（原本は絶対に変更しない）
3. 以下の資料を読み取ってテンプレートに転記:
   - ヒアリングシート → 申請内容シートの各項目
   - 履歴事項全部証明書(PDF) → 法人名・所在地・代表者・設立日・資本金
     ※個人事業主にはこの書類が無い。屋号・現住所・生年月日・事業開始年月日はヒアリング
       シートから取り、資本金は0・決算月は12月固定。無い書類を探して止まらないこと
   - 納税証明書(PDF) → 納税額
   - 損益計算書(PDF) → 売上高・営業利益・経常利益・給料手当・雑給・賞与・減価償却費 → 生産性指標計算シートにも転記
   - 見積書(xlsx) → 申請金額
4. AI判断が必要な項目も可能な限り埋める:
   - 業種コード（事業内容から推定）
   - 経営状況の判定（営業利益がマイナスなら「事業維持に注力」）
   - 地域別最低賃金（所在地から判定）
5. 出力ファイル名: ★顧客名★_★枠名★_AI版.xlsx（資料フォルダ内に保存）
6. 完了後、空欄のセルが何件あるか報告する

■ 注意:
- テンプレート原本のデータは使わない。必ず資料から読み取った値だけを使う
- Pythonのopenpyxlで処理する
- 日本語パスはpathlib.Pathのiterdir()で解決する
- sys.stdout.reconfigure(encoding='utf-8')をスクリプト先頭に入れる
- Excelに書き込む文字列の先頭に「=」を入れない（Excelが数式と誤認するため）
```

---

4. **Claudeが作業を始めるので待つ**（10-20分）
   - 途中で「ツールの実行を許可しますか？」と聞かれたら「許可」を押す
   - 何度か聞かれるので、その都度「許可」でOK
5. **完了したら出力Excelを開いて確認**
6. **空欄が残っている箇所をメモ** → ミーティングで確認する項目

### 空欄が残りやすい項目（正常です）

- 役員のフリガナ（資料に読み仮名がないため）
- アンケート回答欄
- ミーティングでの確認事項（支援事業者との相談項目）
- ファイル添付・操作系の項目（実際の申請画面で操作するもの）

## 3. 給与支給総額の計算（タスク2）

月次の給与データと損益計算書から、給与支給総額と1人当たり給与支給総額を計算します。

### 手順

1. **Claude Codeのチャット欄を開く**
2. **下のプロンプトをコピーして、★の部分だけ書き換えて送信**

---

### コピペ用プロンプト（給与支給総額計算）

```
給与支給総額の計算Excelを作成してください。

■ 顧客名: ★顧客名をここに入れる★
■ 資料フォルダ: c:/Users/★自分のユーザー名★/projects/カラフルボックス/補助金/★顧客名★資料/

■ フォルダ内にある資料:
- 月次の給与支給控除一覧（PDF）: 直近3ヶ月以上
- 損益計算書（PDF）: 直近の決算期
- 賃金状況報告シート（xlsx）: あれば使う

■ 作業内容:
1. 資料フォルダの中身を確認してファイル一覧を出す
2. 損益計算書PDFから以下を読取:
   - 給料手当、雑給、賞与（販管費の内訳）
   - 売上高、営業利益、経常利益、減価償却費
3. 給与支給控除一覧PDFから以下を読取:
   - 従業員ごとの氏名、雇用形態（正社員/パート）、課税支給合計
4. 賃金状況報告シートがあればそこから従業員データを取得
5. 以下を計算:
   - 給与支給総額 = 給料手当 + 雑給 + 賞与（P/Lから）
   - 役員報酬を特定して控除した金額も算出
   - パート・アルバイトのFTE換算（実労働時間 ÷ 標準2080時間/年）
   - 1人当たり給与支給総額 = 給与支給総額 ÷ FTE換算後従業員数
6. 賃上げ計画シミュレーション（基準年比 年3%増の3年計画。各年の計画値は前年の表示整数から常に切り上げ）
7. 2026テンプレートに転記する値の一覧も出す

■ 出力ファイル: ★顧客名★_給与支給総額計算.xlsx（資料フォルダ内に保存）
■ シート構成: 給与支給総額計算 / 従業員別明細 / 賃上げ計画

■ 注意:
- Pythonのopenpyxlで処理する
- 日本語パスはpathlib.Pathのiterdir()で解決する
- sys.stdout.reconfigure(encoding='utf-8')をスクリプト先頭に入れる
- Excelに書き込む文字列の先頭に「=」を入れない
- 給与支給総額から除外する項目: 福利厚生費、法定福利費、退職金
```

---

3. **Claudeが作業を始めるので待つ**（10-15分）
4. **出力Excelを開いて確認** → 特に以下をチェック:
   - 従業員数が合っているか
   - 損益計算書の金額が正しく読み取れているか
   - 1人当たり給与支給総額の値

## 4. うまくいかないとき

### よくあるトラブルと対処法

**Q: 「許可しますか？」が何度も出てうっとうしい**
A: 「常に許可」を選べば、以降は自動で実行されます。

**Q: エラーが出て止まった**
A: Claudeに「エラーが出たので修正して」と送ればOK。大抵は自動で直してくれます。

**Q: Excelを開いたら「内容に問題が見つかりました」と出る**
A: 「はい」を押せば開けます。問題なければそのまま使えます。
もし壊れていたら、Claudeに「Excelファイルが壊れているので修正して再出力して」と送ってください。

**Q: 数値が間違っている気がする**
A: Claudeに「○○の値が違うと思う。損益計算書をもう一度確認して」と具体的に伝えてください。

**Q: 途中で止まって何も起きない**
A: チャット欄に「続けて」と送ってください。

**Q: 全然違うことをやり始めた**
A: チャット欄に「止めて。最初からやり直して」と送ってから、もう一度プロンプトを貼り直してください。

## 5. 出力ファイルの使い方

### 申請書（_AI版.xlsx）
- そのまま申請に使う前に必ず担当者がチェック
- 空欄はミーティングで確認して手入力
- 生産性指標計算シートの計画数値は必要に応じて調整

### 給与支給総額計算（_給与支給総額計算.xlsx）
- 「2026テンプレート転記用」セクションの値を申請書テンプレートに転記
- 1人当たり給与支給総額は「推奨」の行を使う
- 賃上げの水準は**公募要領が根拠**（通常枠 p.11-12 の申請要件、p.25-26 の加点）。150万円以上は **3%以上＋事業場内最低賃金が地域別最低賃金+30円以上**が要件。150万円未満・過去交付なしは要件ではなく加点（3%以上＋30円以上、+50円以上で更なる加点）
- 🔴 **過去に IT補助金2022〜2025 の交付決定を受けた事業者は、申請額を問わず 3.5%以上が必須要件**（公募要領 p.11-12）。この層に3%の計画値を出すと要件未達＝返還リスクなので、手で3.5%に引き上げる（→ [引き継ぎ/02 制度知識ベース](../引き継ぎ/02_制度知識ベース.md)）
- 各年の計画値の丸めを**常に切り上げ**にするのは、公募要領の規定ではなく**社内の運用ルール**（2026-07-21 決定）。四捨五入だと1円差で申請ポータルの伸び率が「2.9%」表示になる事故があったため

## 6. 加点判定（賃上げ加点・項目14/15）— 2工程（v0.2.39〜）

賃上げ加点は **専用の入力台帳**が要る（給与支給総額用の標準賃金台帳は使えません）。加点は「基本給÷月間所定労働時間＝時間換算給与（残業・通勤・各種手当を除く）」を暦月固定で見るためです。

🔴 **賃金台帳が PDF の案件は、ローカルの `katen-judge` スキルが正式経路です**（ツールの「加点判定用賃金台帳の作成」は PDF に対応していません。2026-07-21 決定）。以下は **台帳が Excel で、ツールを使う場合**の手順です。ローカルで行う手順は [チェックリスト_加点判定](チェックリスト_加点判定.md) を参照。

### 手順
1. サイドバーで **都道府県** と **交付申請月（yyyy/mm 例: 2026/06）** を入力。
2. 実行タスク **「加点判定用賃金台帳の作成」** を選び、生の賃金台帳/給与明細（PDF/Excel/CSV、**令和6年10月〜の最大2事業年度分**）をアップロード → 実行。
   - 出力 `{会社名}_加点判定用賃金台帳.xlsx` をダウンロードし、**内容を必ず確認**。
   - AI が所定労働時間を取れなかった人は E列が空欄 → 会社の月平均所定労働時間（例: 160）を手入力。基本給が空欄の月も原本から補う。
3. 確認・補完した台帳をアップロードし、実行タスク **「加点判定」** を実行。
   - 画面に加点①②の対象可否が出て、`{会社名}_加点措置①_結果.xlsx`（通常枠は補助率引上げ・加点措置①）と `{会社名}_加点措置②_結果.xlsx` をダウンロード。

### 注意
- ①の提出シートは申請枠で1枚（通常枠＝補助率引上げ①用／インボイス・セキュリティ枠＝加点措置①用）。ツールが枠に合わせて出力します。
- 役員は判定の母数から除外されます。
- **抽出精度が補助率2/3 を左右**します。最低賃金ぎりぎりの人は必ず原本と突き合わせてください。
- 画面に「データがありません」等の警告（notes）が出たら、対象月の基本給・所定労働時間・交付申請月の入力を確認してください。
