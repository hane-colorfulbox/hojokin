# チェックリスト_加点判定（①②共通＋②固有）

## 第7次以降の適用（2026-11-04）

[変更点と使い方](第7次申請_変更点と使い方.md) と [確認待ち事項](第7次申請_確認待ち事項.md)、[公式資料で判断できることと確認の範囲](第7次申請_公式資料で判断できることと確認の範囲.md) を先に確認する。給与0年度目は見込み値（窓口担当が事務局に照会して確認済み）。給与の当期見込みと生産性の前事業年度実績を分け、過去交付歴・表明・対象人数・根拠の未確認をAIで埋めない。効果報告の比較基準は未確定で、今回は申請向け対応まで。

以下の加点条件は第7次以降用。第1〜6次の訂正・再出力には旧版を使い、公募回・実申請月・原本版を明示する。過去の検証日・会議発言・実装経緯は当時の記録であり、新要件の裏取りとして流用しない。

加点措置①②（賃上げ加点）の判定・提出物作成を丁寧に行うためのチェックリスト。
運用は「CCへの発注書＋人間がやる事実確認」の2層。B〜EはCCに実行させて結果報告を受け、A・C'・Fは人間（担当者・顧客）が確定する。

実案件の教訓ベース（下位分布の全員計算・時給制の実働時間による換算・時間印字なし月の原本確認・除外判断の感度）。個別案件の記録は案件メモ側に置く（このファイルには顧客名を書かない）。

## A. 前提の確定（着手前・人間が決める）

- [ ] 交付申請月を確定（→直近月＝その前月。1か月ずれると判定月がずれる）
- [ ] 公募回を確定（第7次は7。katen-judge では判定だけの実行でも `--call-round` に必ず指定する）
- [ ] 申請枠（①の提出テンプレ選択に影響。通常枠は「補助率引き上げ・加点措置①用」、それ以外の枠は「加点措置①用」。②は全枠共通）。補助率2/3への引上げは通常枠だけ。加点の項目番号は枠で違う（通常枠14・15、インボイス対応類型11・12、電子取引類型8・9、セキュリティ対策推進枠9・10）
- [ ] 都道府県（事業所所在地。勤務地が異なる従業員・派遣の有無も確認）
- [ ] 原本の月カバレッジ：②のみなら基準月（令和8年6月）＋直近月の2か月。①も出すなら令和7年10月〜令和8年9月の12か月

## B. 母集団の網羅性（CC実行・結果を人間が見る）

- [ ] ロスター（標準台帳 or 名簿）と賃金台帳PDF全ページを突合し、未マッチページ0まで氏名解決
- [ ] （転用時）標準台帳ブックの「原本転記」シート群（wagebook-convert の全項目転記）を工程Aの初期ソースに使った場合も、上のPDF全ページ突合（未マッチ0）を省略しない（転記もAI産物＝真はPDF）
- [ ] 各月の母数は「常時使用する従業員」（公式①②の作業要領。労働基準法第20条の「予め解雇の予告を必要とする者」）。小規模事業者の判定と同じ定義を月ごとに当てはめる。役員・事業主本人は入れない。日雇い・2か月以内の期間雇用・季節的業務で4か月以内の期間雇用・試用期間中の人は解雇予告が要らない（労働基準法第21条）ので入れない（ただし日雇いが1か月、期間雇用が決めた期間、試用が14日を超えて続けて使われていれば入れる）。パート・アルバイトも、この例外に当たらなければ入れる。外した人と理由の一覧を報告に残す
- [ ] 基準月・直近月それぞれの在籍者スナップショットを作る（加点は月ごとのスナップショット。R215の「全月在籍」ルールや給与指標のFTEとは別物）
- [ ] 各月について「在籍確認済み・資料不足」「在籍自体が不明」「非在籍確認済み」を区別する。勤務時点が不明な人を「データなし」や非在籍として母数から外さない。非在籍の明示は入退社日・名簿等で確認した月だけにする
- [ ] 基準月にしかいない人（退職者）・直近月にしかいない人（新規入社）を明示的にリスト化する
  - 教訓：基準月のみ在籍の低時給退職者の見落とし→基準月MINが過大→誤って対象外。直近月のみ在籍の低時給新人→直近月MINが下がる→対象外化。どちらも判定を丸ごと覆す
- [ ] 役員を履歴事項全部証明書と突合（就任・辞任日と対象月の前後関係。辞任後に従業員として稼働する二重身分に注意）

## C. 時給（時間換算給与）の導出（CC実行）

- [ ] 日給・時給者：日次（金額÷時間）で時給を確定し、月合計÷月時間で検算
- [ ] 時間の印字がない人を「時給不明→除外」で放置しない。タイムカード・出勤簿等を確認し、他月の時給を使う場合も対象月への適用を原本・契約等で確認する。日額との割切れや複数月の一貫性だけで対象月の時間を確定しない
- [ ] 月給者：分母＝就業規則等で確認した、その人・対象月に適用する所定労働時間。173.33h・160h等の仮定値では提出用判定を確定しない。「最低賃金層ではなさそう」「結論に影響しなさそう」でも代用しない
- [ ] 月別時間の省略は、代表の所定労働時間が根拠付きで確認済みで、各省略月に同じ値を適用できる場合だけ。時給制・日給制・月変動者は各月の確認値を使う。AIが月次時間の中央値・平均値・他月値を作って欠損を補完しない
- [ ] 台帳の基本給列（F〜R列）は基本給（本給）だけ、時間換算の対象月額列（AH〜AT列）は基本給＋下の6種類以外の手当（通常の手当がない人は基本給と同じ額）。どちらにも総支給・課税支給合計・賞与・残業代（固定残業代を含む）・通勤手当・精皆勤手当・家族手当が混ざっていないこと
- [ ] 時間換算給与は厚労省「最低賃金額以上かどうかを確認する方法」で出す（公式①②の作業要領の指定）。除くのは6種類（臨時の賃金・賞与など1か月を超える期間ごとの賃金・時間外/休日/深夜の割増賃金・精皆勤手当・通勤手当・家族手当）だけで、職務手当・役職手当など通常の手当は含める
- [ ] 在籍している全員・全対象月で基本給と対象月額の両方が入り、対象月額 ≥ 基本給になっているか（空欄・0円の月や、対象月額が基本給より少ない月は未確定）。エンジンは様式の【基本給】欄に基本給、【時間換算給与】欄に対象月額÷時間を別々に書くので、様式の手直しは要らない。6種類以外の手当を含めた人は、含めた手当の名目を原本で確かめる
- [ ] AH〜AT列がない台帳（第7次の古いテンプレートで作ったもの）は、F〜R列の1つの月額で両方の欄を作る旧形式として読まれる。通常の手当がある人がいれば、最新の台帳テンプレートに移して入れ直したか
- [ ] 全員の時間換算給与 ≥ その期の地域別最低賃金（割れたら抽出ミス・時間欠落のシグナル。judgeの安全網警告を必ず読む）
- [ ] 55円境界の丸め：時間は小数第4位まで保持（1位丸めは境界判定を覆し得る）

## C'. 事実確認（人間・顧客経由でしか分からないこと）

- [ ] 家族・専従者・名目給（月数千円〜数万円）の人の身分（従業員か役員・専従者か）
- [ ] 時間記録のない従業員のタイムカード・出勤簿の有無（ヒアリングシート注記「時間記載なしはタイムカード併せて提出」）
- [ ] 月給者の就業規則上の所定労働時間
- [ ] 母数の判断に要る雇用条件（日雇いか、契約期間が2か月以内か、試用期間中か、決めた期間を超えて続けて使われているか）。判断がつかない人は「未確定」のまま止める
- [ ] 職務手当・役職手当など、時間換算給与に含める手当の有無と金額（給与明細・賃金規程）

## D. 判定の検算（CC実行・独立2系統）

- [ ] エンジン判定（read_bonus_wage_ledger→judge_bonus_points。ローカルは katen-judge スキルの `run_katen_judge.py`、ツールは「加点判定」タスク＝同一コード。ツールはフッターの版が v0.2.99 以上のときだけ第7次対応版で、それより前の版では第7次の加点判定をしない）と、手計算（両月の時給リストからMIN・差額）の一致。`run_katen_judge.py` には判定だけのときも `--call-round` に実際の公募回を渡し、レポートの「公募回」表示が一致していること
- [ ] 公式②シート：D5=申請月、N14=EDATE(D5,-1)、D7/D8のMIN配列式が生きているか、例行（16行目）が範囲外か、D9/D10の判定式温存
- [ ] 期間①ブロック（B〜H列）と期間②ブロック（J〜O列）が、それぞれ正しい在籍者を持つか（独立2ブロック・行対応しない設計）
- [ ] 両月のMINを決めた本人の原本ページを開いて目視（氏名・日額・時間）
- [ ] ②シートの最賃欄（E/M列のVLOOKUP表示）は合否に使われない。第7次の公式②のマスタは令和7年度の単一値なので、直近月が令和8年度改定の発効後でも令和7年度の額が表示される（例：東京は1,226円と表示、法定は1,280円）。山形は②のマスタが1,031円（正しくは1,032円）。**原本のマスタは直さず**、適用した法定額と発効日を説明メモに書く（表示が古いと事務局の疑義を招いた前例があるため）。差し替えるのは公式の更新版が出たときだけ
- [ ] 公式②で Excel の「データ」→「すべて更新」を実行していないこと（表示用マスタが隠しシートの令和6年度の値に戻るおそれがある。Excel での実際の動きは未確認）
- [ ] 旧回の訂正用（第1〜6次）の様式・台帳を第7次の案件に使っていないこと（第7次以降の様式は B2 に【第７次公募回以降用】）

## E. 感度チェック（CC実行・結果が覆る条件の明示）★最重要

- [ ] 「基準月MINより低い人が基準月に隠れていないか」——時給不明者・除外者を含む下位全員について明示的に問う（基準月側は低いほど対象に有利。差の向きに注意）
- [ ] 「直近月に低時給の新人が隠れていないか」——直近月側は低いほど不利
- [ ] 除外判断（役員・家族・名目給）を反転させた場合に判定が変わるか試算する。変わるなら C' の顧客確認を「必須」に格上げ
- [ ] 申請月が±1か月ずれた場合に、必要な追加資料（直近月の台帳）と判定への影響を明記

## F. 提出前（人間）

- [ ] 説明メモに前提・根拠・（あれば）訂正経緯・残リスクを明記してあるか（②の最賃欄の表示と、適用した法定額・発効日の違いを含む）
- [ ] C' の事実確認の回答が揃ったか（在籍・時間・算入範囲が未確定の間は「未確定」と明示し、該当する提出用様式の確定生成・共有を止める）
- [ ] 社内ダブルチェック（賃上げ関連の窓口経由）
- [ ] 成果物の置き場所：顧客PIIを含むためgit管理外。Drive配置は共有ポリシーに従う

## 運用メモ
