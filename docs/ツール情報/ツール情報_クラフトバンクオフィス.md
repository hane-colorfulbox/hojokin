# クラフトバンクオフィス（CraftBank office）

検証ステータス: **grounded**（中核機能・主要効果を公式/一次出典で裏取り済）
取得日: 2026-06-23

## 1. 製品名／提供元

- 製品名: **クラフトバンクオフィス**（CraftBank office / 略称 CBO）
- 提供元: **クラフトバンク株式会社**（本社 東京都中央区、ドメイン craft-bank.com / corp.craft-bank.com）。販売パートナーとしてソフトバンク株式会社も同製品を取り扱う
- ⚠ 同社はもう一つ工事マッチング事業「クラフトバンク（協力会社検索/受発注プラットフォーム）」も持つ。**補助金対象は経営管理SaaS側の「クラフトバンクオフィス」**。マッチング側と取り違えない

## 2. 対象業種・規模

- 職人を自社に抱える**専門工事会社・建設工事会社**。工種・規模・エリア問わず（全国47都道府県・全29工種に導入実績、利用職人14,000人超）
- 中小の専門工事会社が主対象

## 3. 主要機能（公式office・ASPIC・ITトレンド・Softbankで裏取り）

- 案件管理（現場・工事案件の情報を一元管理・進捗共有）
- 案件ごとの原価管理（現場別の原価・利益をリアルタイム自動算出・可視化）
- 経営レポート／ダッシュボード（収支・経営状況を自動表示）
- 見積書作成・管理（原価ベース、既存書式の再現）／請求書作成（見積→請求書へ自動変換）
- 日報作成・管理（**LINE連携**で職人がスマホ入力、複数書式・自動集計）
- 勤怠・打刻・入退場管理（スマホ完結、労働時間自動集計、休暇管理）
- 工程管理（ドラッグ&ドロップ予定管理・自動通知）／給与計算（勤怠連携、日給月給対応）
- 経費精算（現場からリアルタイム報告→管理表へ自動反映）
- 顧客管理・協力会社管理（品質評価の可視化・ランク付け）／入出金管理
- 写真・文書／フォルダ管理（現場写真の自動整理、報告書作成）／車両・道工具管理
- 工事台帳・管理会計・財務諸表出力／在庫管理／営業管理

## 4. 解決する課題

- 現場ごとの収支が不明確で決算後に赤字が判明する「利益の見えない経営」
- 現場後の日報確認・見積作成で毎晩2〜3時間の事務作業負担
- 社長が見積・原価・人員配置を一手に担う属人化
- 紙日報・Excel請求・LINE/電話/カレンダーなどバラバラなツールの乱立と転記ミス
- 建設業の2024年問題（時間外労働上限規制）への対応負担

## 5. 導入効果

- 事務作業時間を最大80%削減（提供元公表値・ASPIC記載）
- 1人当たり生産性を約2倍に向上（同上）
- 事例: 月15件の案件増加・売上150%超（シンテック）／転記作業を1日あたり1/4に削減（テクニカル・ジャパン）
- 原価・利益のリアルタイム可視化で現場収支を即時把握、脱属人化（社長が現場にいなくてもスマホで把握）

## 8.【事業内容255字用サマリ】

- 概要: クラフトバンクオフィスは、職人を自社に抱える専門工事会社向けのオールインワン経営管理SaaS。案件・原価・見積・請求・日報・勤怠・工程・給与計算・経営レポートまで、工事会社の事務作業をクラウドで一元的にデジタル化する。職人はLINE連携でスマホから日報や勤怠を入力でき、入力データは自動集計される。
- 課題: 建設工事会社では、現場ごとの原価・利益が見えず決算後に赤字が判明する、毎晩2〜3時間の日報確認や見積作成に追われる、社長に業務が集中し属人化する、紙やExcel・LINEなどバラバラなツールで転記ミスが起きる、といった課題があり、2024年問題（残業規制）への対応も迫られている。
- 解決: 案件・原価・見積・請求・日報・勤怠・工程・給与計算・経費精算・経営レポートを1つのシステムに統合し、現場のスマホ入力データを自動集計。見積から請求書への自動変換、現場別の原価・利益のリアルタイム可視化、ダッシュボードでの経営状況把握により、転記作業と属人化を解消し事務工数を削減する。
- 効果: 事務作業時間を大幅に削減し、1人当たり生産性を高める。原価・利益がリアルタイムで見える化され、社長は現場にいなくてもスマホで進捗・収支を把握できる。導入企業では受注件数増・売上向上や転記作業の大幅削減などの成果が報告されている。
