## 1. 製品名／提供元

- 製品名: **Scale人事評価**（スケール人事評価）。製品ドメイン scale-hr.cloud
- 提供元: **カラフルボックス株式会社**（自社開発・自社提供。同社自身がデジタル化・AI導入補助金の支援事業者）
- リリース: 2026年3月25日。上位に「MCP連携オプション／ベータ」あり（MCPサーバーは2026年4月）

## 2. 対象業種・規模

- 中小企業全般（業種不問）。ITに詳しい担当者がいない企業でも運用できる前提
- 導入事例は10〜50名規模（訪問看護・介護、看板の企画製作施工、精肉店、歯科医院、建設機材リース等）
- 人事評価制度がない／Excel・紙で属人運用している中小企業が主対象

## 3. 主要機能（◎=公式scaleページで裏取り済 / ○=社内ナレッジ由来・公開未確認）

- ◎ 評価シートの作成・配布・回収・集計を一元管理、ステータス一括管理、多段階承認ワークフロー
- ◎ 評価シートテンプレート（職種・職位・等級別）、評価項目の一括アップロード
- ◎ 役割別ダッシュボード、掲示板・お知らせ
- ◎ 期日のメール自動通知（評価忘れ・遅延防止）、進捗のリアルタイム可視化
- ◎ ユーザー管理・閲覧権限設定（PR TIMESは「4段階権限」と記載）
- ◎ データのCSV出力（既存の給与・人材管理ツールと連携）
- ◎ 1on1機能、マルチデバイス／スマホ対応（閲覧・入力）
- ◎ **AIコーチ**：定性目標の添削／評価コメント自動生成／1on1トピック提案／評価結果分析（甘辛・偏りの可視化）／給与査定シミュレーション
- ◎ **MCP対応**：搭載MCPツール82種、対応環境 Claude Code・Claude Desktop・Cursor 等（AIエージェントが評価データに直接アクセスし対話で操作）
- ○ ワークフロー詳細（目標設定→中間→最終、1〜3次承認、差し戻し・再提出）、テンプレ上限値（評価軸最大5・項目最大100）、アラート閾値、リマインドのタイミング（社内ナレッジ記載・公開未確認）

## 4. 解決する課題

- Excel・紙運用の限界（同時編集不可、バージョン乱立、集計に多大な工数、検索困難、漏洩リスク）
- 評価基準の属人化・経営者の主観偏り → 従業員の不公平感・納得感の欠如
- 進捗が見えない（誰が完了したか不明、対応漏れ・期日超過）
- フィードバックの形骸化、評価データが昇格昇給・配置・育成に活きない
- 評価業務の工数過多、評価者のスキル不足、IT担当不在で導入・定着を自走できない

## 8.【事業内容255字用サマリ】

- 概要: Scale人事評価は、カラフルボックス株式会社が2026年3月にリリースした中小企業向けクラウド型人事評価システム。目標設定・多段階評価・1on1・フィードバック・給与査定・データ分析まで人事評価の全工程をクラウドで一元管理し、AIコーチ（目標添削・評価コメント生成・1on1トピック提案・甘辛分析・給与査定シミュレーション）が評価者と経営者の判断を支援する。
- 課題: 多くの中小企業は人事評価をExcelや紙で運用しており、評価基準の属人化による不公平感、進捗が見えず対応漏れが起きる、集計に多大な工数、フィードバックの形骸化、蓄積データが人事判断に活きない、といった「制度はあっても正しく運用できない」課題を抱えている。
- 解決: 評価シートの作成・配布・回収・集計と多段階承認ワークフローをクラウドで一元化し、役割別ダッシュボードと自動リマインドで進捗を可視化・抜け漏れ防止。AIコーチが目標添削・評価コメント生成・1on1アジェンダ提案・評価者の甘辛分析・給与査定シミュレーションを行い質と公平性を底上げ。CSV出力で既存の給与・人材管理ツールと連携する。
- 効果: シート作成・配布・集計の自動化で評価業務の工数を削減し、自動リマインドで期限内完了を高め対応漏れを防止、評価プロセスの透明化で従業員の納得感・満足度を向上させる。生まれた時間を1on1・育成・対話に再配分し、データに基づく評価制度の継続改善と根拠ある昇給・査定を実現する。
