# 導入ツール情報コンテキスト（INDEX）

補助金「事業内容(255字)」を、申請者が**今回導入するITツールの実際の機能**に沿って書くための素材集。
事業内容生成プロンプト（[ai_extractor.py](../../hojokin/ai_extractor.py) の `PROMPT_AI_JUDGMENT`）には現状ツール「名」しか渡っておらず、機能の中身はAIの推測になる。ここに各ツールの機能・効果を集約し、将来は `tool_name` から該当ファイルの【事業内容255字用サマリ】を引いてプロンプトに注入できるようにする。

取得日: 2026-06-23 / ソース: **IT補助金コンソール（console.it-shien.smrj.go.jp）の各社登録「ITツール概要」原文＝最上位の根拠** ＋ 各社公式HP・PR TIMES・社内資料（Scale）。各ファイルの「公式登録情報」節がコンソール登録値。

## AI搭載有無と枠（重要）

- **生成AI搭載**: Scale / ClipLine / irohana → 案件により **AI導入枠** も視野。事業内容でAI機能を具体的に書ける。
- **AI非搭載**: クラフトバンク / ピスケス → **デジタル化枠**想定。事業内容で「AI」を強調しない（登録上も非搭載）。
- ブレイン経由は導入ツール次第（当該ツールのコンソール登録で確認）。

## 申請ツール名（ヒアリングB53）との照合用 別名

ヒアリングの「申請ツール名」は表記ゆれが多い。事業内容生成でツールを引き当てる際のキー候補：

- Scale人事評価 ← Scale / スケール / スケール人事評価 / Scale HR / scale-hr / カラフルボックス 人事評価 / AI人事評価システム
- クラフトバンクオフィス ← クラフトバンク / クラフトバンク office / CraftBank office / Craft Bank Office / CBO
- ClipLine（ABILI Clip）← ClipLine / クリップライン / ABILI / アビリ / ABILI Clip / アビリクリップ
- ピスケスアポ ← ピスケス / ピスケス・アポ / Pisces Apo / e-pisces / 歯科予約 ピスケス（※CTI・SMS・LINEは別登録の機能拡張）
- irohana ← いろはな / イロハナ / **irohana visa**（ビザ・在留）/ **irohana match**（人材紹介）/ **irohana study**（2号試験eラーニング）/ スモール・スタンダード・ラージ / 特定技能 管理システム / 外国人雇用DX
- ブレイン ← ブレイン / 株式会社ブレインコンサルティングオフィス / ＰＳＲコンソーシアム / PSR ／（導入ツール例）ちゃっかり勤太くん・目標管理クラウドcbox・CRS人材募集管理・KiteRa Pro・HRbase PRO 等 ※実際の製品は案件ごとに特定
  - ⚠ 旧INDEXに書いた BakeryScan/EatScan/DCBEE/BR-POS 等は**全て誤り**（同名他社）。使わない。

## 検証ステータスの凡例

- **grounded（公式登録）**：コンソール登録「ITツール概要」原文で機能・効果・プロセス・AI有無・価格を確認済。事業内容にそのまま使える（数値も登録値＝申請上の正）。各ファイルの「公式登録情報」節を参照。
- **提供元特定済（製品は案件ごと）**：ブレインのように1社1製品でない場合。申請案件のツール名でコンソール「ITツール一覧」を引き、当該ツールの登録概要から255字を作る。
- 各ファイルの「検証ノート」には公開HP由来で未確認の補足（第三者サイトの料金等）を残してある。コンソール登録と公開HPが食い違う場合は**コンソール登録を優先**。

## 各ファイルの構成

1. 製品名／提供元　2. 対象業種・規模　3. 主要機能　4. 解決する課題　5. 導入効果　6. 料金・補助金枠/類型　7. 出典　**公式登録情報（コンソール原文・最上位の根拠）**　8.【事業内容255字用サマリ】（概要/課題/解決/効果の4要素）　9. 検証ノート

## 将来の配線メモ（別ターン・未実装）

- 事業内容生成時、`tool_name`（見積orヒアリングB53）→ 本INDEXの別名で該当ファイルを引き当て →【事業内容255字用サマリ】or「公式登録情報」概要を `PROMPT_AI_JUDGMENT` に注入する。
- irohana/ブレインは製品が複数 → 別名だけでなく「visa/match/study」「ちゃっかり勤太くん」等の製品語でサブ特定する分岐が要る。
- v0.2.73フィードバックF3②「ツール資料Drive読込」と同思想。Drive配置/環境変数化も検討。

## 要対応

- 支援事業者一覧の**13行目（Business Performance Analytics / 野田）** および14行目以降は未収集（今回のコンソール・ログイン対象外）。対象なら同じ枠組みで追加する。
- ブレイン／irohana は案件ごとに導入製品が変わるため、**実際の申請案件のツール名が来たら**当該製品のコンソール概要を引いて255字化する（本INDEXは入口）。

## 機密注意

- 自社製品＋公開/登録のベンダー情報のみ。顧客企業名・支援事業者の担当者氏名/連絡先・ログイン資格情報は載せない（ツール機能のみを扱う）。コンソールは閲覧のみ（提出/編集/削除はしない）。
