## 3. 主要機能（◎=公式サイトで裏取り / △=第三者サイトのみ）

- ◎ 予約管理（院内状況が一目で分かる／1日分の全予約表示／1週間の予約状況／空き枠検索／予約ページのタブ切替）

- ◎ リマインド／SMS・ショートメール自動配信（予約忘れ・予約確認）
- ◎ LINE連携（予約案内・患者コミュニケーション）
- ◎ CTI／着信ポップアップ（電話着信時に患者情報を画面表示）
- ◎ キャンセル待ち機能（空き枠を待機患者で即穴埋め）
- ◎ 患者管理（通院・キャンセル・遅刻歴を一発表示、患者特性をアイコン表示）／かぞく（家族）管理
- ◎ レセコン（医事会計）患者連携／リライト診察券／プライバシーモード
- ◎ 技工物（補綴物）の納期管理（「技工物がない」を防ぐ）／スタッフシフト管理
- ◎ 未予約者のかんたんフォロー（来院中断・未予約患者を抽出し再来院促進＝リコール）／ナナメドリ（斜め予約）
- △ 5分〜60分単位の予約設定、治療内容・担当医師別の色分け表示、来院データ分析・経営改善、オンプレミス（院内サーバ設置）型 ← 第三者サイト記載で公式未確認

## 4. 解決する課題

- 電話・紙台帳による予約管理の手間とミス・ダブルブッキング
- 予約忘れ・無断キャンセルによる稼働率低下と受付の催促負担
- 来院中断・未予約患者の取りこぼし（リコール漏れ）
- 予約スケジュールが煩雑で院内状況・空き枠が把握しづらい
- 電話対応時に患者情報がすぐ分からず受付が非効率
- 技工物の納期管理ミス、患者・家族の履歴管理が属人的、スタッフシフト管理が煩雑

- △ 患者待ち時間の短縮・院内運営の効率化／来院中断患者の掘り起こしによる再来院促進
