# 【ご案内】今後の進め方と、考えておいていただきたいこと

本日はお時間をいただきありがとうございました。今回の補助金のお手続きでは、経営者様ご本人と社外の専門家とのオンライン面談（約1時間）があります。その準備のため、後日カラフルボックスの担当者から、お電話（15分ほど）やメール・入力フォームで下記のことを伺います。ざっとで結構ですので、考えておいていただけますと当日のお話が短く済みます。

## この後の流れ（3ステップ）

1. 後日、カラフルボックスの担当者からお電話を差し上げます（15分ほど）
2. 伺った内容をもとに、面談予約の入力文のたたき台を当社で作成し、社長にご確認いただきます
3. 経営者様ご本人が、社外の専門家とオンラインで面談します（Zoom・約1時間）

## お電話までに考えておいていただきたいこと（7つ）

1. **いまの主な業務のやり方** — 経理・請求・受発注・在庫・勤怠・顧客管理などが、紙か・Excelか・何かのソフトか（ソフトはお名前まで）。ChatGPTなどのAIを使っているか（使っていなければ「使っていない」で結構です）
2. **会社をこれからどうしていきたいか** — 1年後・数年後のイメージ（売上を伸ばす・今の人数で回す・人手不足を補う など）。効率化で生まれる時間や余力を何に活かしたいか（賃上げ・人を増やす・営業に力を入れる など）も、あれば一言
3. **いま一番お困りのことと、今回のツールに決めた理由** — 時間がかかる・ミスが多い・特定の人しかできない・人が採れない/辞める など。決めた理由は、価格・操作の簡単さ・サポート・いまの仕組みとつながる など、ご自身の決め手を
4. **導入の進め方のイメージ** — 導入前にやっておくこと・導入してすぐやること・1年後の目標。使い始めまで何ヶ月くらいかかりそうか。心配な点があればそれも
5. **社内でどなたが担当するか** — 社長ご自身か、担当の方を立てるか（担当の方ならお名前と役割）
6. **社長ご自身がどう関わっていくか** — 方針を決める・進み具合を見る・社員に直接伝える など、ご自身の言葉で話せるように
7. **御社ならではの強み・大事にしていること** — あれば一言（無ければ結構です）

## ご安心ください

- 社員数や作業時間などの数字は「だいたい」で結構です。分からないものは「分からない」で大丈夫です（無理にお調べいただく必要はありません）
- 資料のご準備は不要です。口頭でお答えいただければ、文章にまとめるのは当社が行います

## オンライン面談の候補日について

面談には経営者様ご本人のご出席が必要です（代理の方はご出席いただけません）。ご都合のよい候補日時を3つ以上（それぞれ2時間以上の幅で。面談自体は約1時間）お考えおきください。まだお決まりでなければ、お電話の際のご相談で結構です。
