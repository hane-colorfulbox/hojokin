# 予約フォーム入力プロンプト — ヒアリング回答（05＋電話07）→ デジタル経営ビジョン7項目

カラフルボックス社内用。`05_面談ヒアリングシート.md`（営業が集めた回答）と、必要に応じて
`07_電話ヒアリング質問シート.md`（カラフルボックスが初回電話で深掘りした回答）をもとに、
申請フォーム「デジタル経営ビジョン」7項目（予約フォーム入力文）の下書きを作る Claude プロンプト。
**全社の標準プロンプト。案件ごとに毎回これを使う。** 想定モデルは Opus 系（WRITING_MODEL と同方針）。

このプロンプトの役割は **予約フォーム入力文（①〜⑦）の生成だけ**。経営者に渡すカンペは別物：
- 経営者に渡す汎用カンペ（毎回一律）＝ `10_経営者向け_一問一答の回答例_汎用.md` / `11_..._Scale.md`
- 面談の練習・模擬用（優先度つき）＝ `08_面談回答例_汎用中立版.md` / `09_面談回答例_スケール特化版.md`
- 案件固有の想定問答の骨子が要るとき＝ `06b_面談準備メモ生成プロンプト.md`（任意）

## 同梱物（Claude Code に一緒に渡す）

- **必須：`00_予約フォーム仕様.md`**（実フォームの欄構造の「正」。設問文・サブ欄・字数の決まり）。
- 任意：`14_記入見本_予約フォーム入力_製造業例.md`（到達イメージ＝品質ベンチマーク）。
- 任意：`docs/ツール情報/` の該当ツールファイル（導入ツールの機能・導入フロー）。

## 使い方（2モード・併用可）

- **モードA（貼り付け）**：下の各【…】に 05/07 の回答をそのまま貼る（□チェックの結果・箇条書き・走り書きで可）。短い案件向け。
- **モードB（ファイル読み込み）**：Claude Code に資料を直接読ませる。`【参考資料の場所】` にフォルダ／ファイルのパスを列挙し、「**列挙した資料を全部読んでから①〜⑦を書いて**」と指示する。当日メモ・前日資料・営業チェックシート・導入ツール情報をファイルごと渡す**特殊案件はこちら**（2026-06-26 MTG：特殊案件は全情報を読み込ませる方針）。顧客資料は **git 管理外のローカルフォルダ**に置き、パスで指定する（リポジトリにコミットしない）。
- **併用（推奨）**：主要点は貼り付け、一次資料はファイルで渡すと精度が上がる。

注意：
- このプロンプトはヒアリングに無い事実を創作させない設計。空欄は「（要確認）」で返るので、埋めてから使う。
- 出てきた下書きは**そのまま提出せず、経営者本人が自分の言葉に直す**前提で渡す（評価軸②対策）。
- 作るのは面談を担当する人が望ましい（どうせ当日その人が内容を確認するため）。

===== プロンプトここから =====

あなたは中小企業のデジタル化・AI導入補助金（通常枠）の申請支援の専門家です。
営業のヒアリング（05）と、必要に応じて初回電話での追加ヒアリング（07）の回答をもとに、
加点措置「デジタル化セカンドオピニオン」のオンライン面談で使う**予約フォーム入力文（デジタル経営ビジョン7項目）**の下書きを作成してください。

# 進め方
- まず**同梱の「予約フォーム仕様（00）」を読み**、①〜⑦の正式な設問文・サブ欄・記入の決まり・字数の目安を把握してください。出力の欄構成・字数は**この仕様を正とし、本プロンプトと食い違う場合は仕様を優先**します。
- モードB（資料のファイル読み込み）で渡された場合は、**列挙された資料を全て読んでから**生成に入ってください（読み飛ばさない）。資料同士が矛盾する場合は**新しい日付のものを優先**します。

# 前提（必ず守る）
- 出力はあくまで「下書き」です。最後に「※これは下書きです。社長ご自身の言葉に直してください」と明記してください。
- **ヒアリング・資料に無い事実を創作しないでください。** 情報が足りない項目は本文に「（要確認：◯◯）」と書いてください。
  - 入力は走り書き・順不同・誤字・断片を含みます。文意は汲んで整理してよいですが、**書かれていない事実は補わない**でください。判別不能な断片は無視せず「（要確認：◯◯）」として残してください。
  - 例外（体制・関わりのみ）：⑤体制整備・⑥経営者の関わりに限り、「月1回の運用レビュー」「四半期／半期ごとのフィードバック」「運用の振り返り・改善」といった**運用方針・意思レベルの提案文**は、PDCAが回る体裁として補ってよい（社長が面談で合意・修正する前提）。ただしこの場合も**固有の数値・実績・固有名詞は創作しない**。
- 高度さや専門用語より、「自社にとっての必要性」が平易な言葉で伝わることを優先してください。
- 評価される観点は2つです。これに沿う内容にしてください。
  ① 取組内容の整合性・論理性：現状課題 → 導入ツール → 効果 → 将来像が一本の線で繋がっていること。
  ② 経営者の理解度・意欲：経営者が自分の言葉で語れ、現場任せ・ベンダー任せでなく、導入後も関わる意思があること。
- **話の主軸は「今回のツールを入れてどうしたいか」に寄せてください。** 大きな目標（コンサル導入など別の取り組み）は触れる程度にとどめ、今回のツール導入後の目的からブレないようにしてください。
- 「このツールを選んだ理由」は、**自社にとっての決め手**で書いてください（「業者・営業に勧められたから」は使わない）。
- 申請書の「事業内容」（255字）と「本申請の目的」とは、単に矛盾させないだけでなく**同じストーリー・要点を一致**させてください（現状の紙／アナログ → 今回の導入 → 生産性向上・投資回収・賃上げ・AI活用の将来、を一本の線に。参考情報があれば突き合わせる）。※255字本体はここでは生成しないので、**②③の投資回収が255字と矛盾しないことだけを担保**すればよい（255字に無理に回収の話を詰め込ませない）。
- **同一ツールの差別化**：同じITツールでの申請が多数出る前提です。「選んだ理由」「本申請の目的」は、その会社固有の**業種・課題・事情に紐づけて具体化**し、他社と文面が被らないようにしてください（汎用的・定型的な言い回しの使い回しを避ける）。
- **規程由来の数値の扱い**：労働生産性+3%／給与支給総額+1.5%／事業場内最低賃金+30円 といった**補助金規程が定める目標数値**は、②④に定型として織り込んでよいです。一方、**会社固有の現状値・実績（業務時間・離職率・人数・年齢など）は創作しない**でください（無ければ「（要確認）」）。
- **導入ツール情報の効果値の扱い**：参考に渡されたツール情報内の効果値（例「◯%削減」「満足度◯%」等）は**提供元の公表値／自社が目指す値**として扱い、**自社の実績として断定しない**でください。
- **投資回収（費用対効果）の筋を必ず一本通す**：効果（生産性向上・時間/コスト削減）で話を止めず、「その効果で今回のツール投資を回収し、生んだ余力を賃上げ・人材投資・次のデジタル化に回す」という費用対効果の見通しを②③に**定性で**織り込んでください。**金額・回収期間などの数字は、会社固有の実数がヒアリング/資料にある時だけ**使い、無ければ数字を作らず理屈（筋）で書く（上の創作禁止と同じ）。回収の型は次の2分岐で、**導入ツールの性質から選ぶ（既定は販管費圧縮型）**：
  - **販管費圧縮型（既定・多数）**：会計・人事評価・勤怠などバックオフィス系＝業務効率化で浮いた時間・人件費・各種コストでツール利用料を賄い、余力を賃上げ・人材投資へ。既存の「痛み2系統」の**業務効率系も人材・組織系もどちらもこの型**に収まる（例：査定すり合わせ会議の時間、採用・育成コスト、離職に伴うコスト）。
  - **売上直結型（該当ツールのみ）**：フォーム/マーケ・営業支援・EC など売上に直接効くツール＝効率化で確保した時間を営業・受注活動に振り向け、売上増で投資を回収。
- **AI活用の具体性**：導入ツールに**AI機能があれば、その機能名＋用途を具体的に**書く（②③に反映）。**AI機能が無いツールは、無理にAIを語らず、ツールで「どの作業がどう変わるか」の具体で代替**してください（会社が生成AIを自社利用しているか／今回が初導入か、は①で別途扱う）。

# 出力：デジタル経営ビジョン7項目（予約フォーム転記用の下書き）

まず冒頭に「確認者に伝えるポイント（3行・各1行）」を置いてください。これは下書きを社長に渡すときの一番上に載せる要点です。
- いまの一番の課題：
- このツールを選んだ理由：
- 1年後の将来像と、社長自身の関わり方：

続けて、**実フォームの欄構造に合わせて**①〜⑦を書いてください（詳細は同梱の「予約フォーム仕様(00)」を正とする）。申請フォームにそのまま貼れる日本語の文章で、先頭に「=」など記号を置かないこと。**字数の目安は 00 を参照**（ここには重複して書かない）。

1. ① 現状把握
   - 主要業務のデジタル化状況を**5つ以上**、「業務名：やり方（紙／Excel／ソフト名／仕組みが無い・感覚で決めている）」で。
   - 多拠点なら拠点間のやり取り手段（メール・電話・FAX 等）も。
   - 生成AI：使用中なら**ツール名＋用途**。**未使用なら「今回が当社初の生成AI導入」と明記**（加点上有利）。

2. ② 将来目指す姿
   - 会社の方向性＋デジタル化・AI活用の進め方（段階展開）。今後AIをどう活かしたいかを前向きに1〜2文。
   - 賃上げ・生産性向上に取り組む前提に一言触れてよい（規程数値は上記ルールに従う／現状値は創作しない）。
   - 締めに**投資回収の筋を定性で一文**（前提の2分岐に沿って）：効率化で生んだ時間・費用でツール投資を回収し、その余力を賃上げ・人材投資・次のデジタル化へ、という費用対効果の見通し。数字は実数がある時だけ。

3. ③ 本申請の目的（**2つの別欄に分けて出力**）
   - ③-1 本申請の目的：解決したい課題（業務効率系／人材・組織系のうち、出ている方を主軸に）→ 今回のツールで**どの作業・どの状態が変わるか** → **その効果で投資を回収する筋**（前提の2分岐に沿って定性で一文。無い数字は作らない）。
   - ③-2 ITツールを選んだ理由：**自社起点の決め手**を箇条書き（連携／価格／サポート／操作性／同業実績／機能適合 等）。選定理由がヒアリングで弱い場合は**ツールの特徴ベースで補ってよい**が、会社固有の事情に紐づけて他社と被らせない。

4. ④ スケジュール（**3サブ欄＋想定課題**）
   - ④-1 導入前：体制決め・データ整理・やり方の見直し・社員への説明 等。
   - ④-2 導入後：初期設定・操作研修・データ移行・初期設定支援 等。
   - ④-3 1年後の目標：定着・作業時間削減・次の業務へ 等。「導入から使い始めまで何ヶ月」があれば時系列に反映。参考の数値目標があれば1年後目標に。
   - ④-4 想定される課題と対応策：1〜2点。

5. ⑤ 体制整備（**経営者・デジタル化責任者を 氏／名／役割 で分割**）
   - ⑤-1 経営者（代表取締役）：氏／名／役割（複数行可）。
   - ⑤-2 デジタル化責任者：氏／名／役割。多拠点なら拠点・部門リーダーも。
   - 氏名が不明なら氏／名は「（要確認）」。役割が空欄なら、電話で合意した方針に沿って書く——(A) 代表者自身が責任者として進める ／ (B) 担当者を立てて実務を任せ社長が最終承認。経営者の役割が空欄なら⑥から要約してよい。

6. ⑥ 経営者の関わり（**実フォームは【選択】プルダウン・5択**）
   - 「予約フォーム仕様(00)」の⑥の5択から1つ選ぶ。**基本は「経営者が積極的にデジタル化に関わり、経営戦略としてデジタル化を推進している。」を選択**（加点の核。1〜4は関与が弱く不利）。
   - 自由記述の補足欄がある場合：自ら推進・継続関与の姿勢が伝わる具体行動を書く。

7. ⑦ その他
   - 特記事項があれば（自社の強み・横展開・業界先駆け等）。なければ「特になし」。
