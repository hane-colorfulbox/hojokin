# 電話確認メモ生成プロンプト — 05＋会社HP → その会社に聞く「電話確認メモ（カンペ）」

カラフルボックス社内用。営業ヒアリング（`05_面談ヒアリングシート.md` の回答）と**その会社のホームページ**をもとに、
初回電話で「この会社に何を聞けばいいか」を絞り込んだ**電話確認メモ（カンペ）**を生成する Claude プロンプト。
汎用の `07_電話ヒアリング質問シート.md` を毎回読んで取捨選択する手間（電話前の準備時間）を短縮するのが目的。
想定モデルは Opus 系。

このメモは「電話の前に読む・電話中に見る」カンペであり、その場で答えを書き込めば、そのまま `06`（予約フォーム入力プロンプト）の
【電話ヒアリング回答（07）】に渡せる。

## 渡すもの（Claude に一緒に渡す）

毎回貼るのはこの2つだけ：
- **この会社の営業ヒアリング（05）の回答**（貼り付け）
- **その会社のホームページのURL**（人間が貼る＝AIが読む。読めない環境ならHP本文を貼る）

参照（手元にあれば一緒に渡すと精度が上がる・無くても動く）：
- `00_予約フォーム仕様.md`（予約フォームが要る情報①〜⑦の「正」）／`07_電話ヒアリング質問シート.md`（汎用の質問バンク＋ルールの「正」）。本プロンプトは①〜⑦とルールの要点を内蔵しているので、これらが無くても電話確認メモは作れる（あればより正確）。
- 任意：`14_記入見本_予約フォーム入力_製造業例.md`（到達イメージ）。

## 使い方

1. 下の「===== プロンプトここから =====」をコピーして Claude（Claude Code / チャット）に貼る。
2. `【この会社の05（記述課題込み）】` に、営業が集めた05の回答を貼る（チェック結果・記述・走り書きで可）。
3. `【会社HP】` に **会社ホームページのURLを貼る**（人間が貼る）。Claude がそのURLを読める環境（Claude Code の WebFetch／ブラウジング可のチャット）ならURLだけでよい。**読めない環境なら、HPの本文（会社概要・事業内容・強みのページ等）をコピペで貼る**。HPが無ければ「なし」。
4. 出てきた「電話確認メモ」を見て電話 → 答えをメモ欄に書き込む → その内容を `06` に渡して予約フォーム入力文を作る。

注意：HP・05に書かれていない事実を断定させない設計。数字は概算でよく、無ければ「未計測」で定性に逃がす（無い数字は作らない）。

===== プロンプトここから =====

あなたは中小企業のデジタル化・AI導入補助金（通常枠）の申請支援の専門家です。
加点措置「デジタル化セカンドオピニオン」に向けて、営業ヒアリング（05）とその会社のホームページをもとに、
**初回電話でこの会社に確認すべきことだけを絞った「電話確認メモ（カンペ）」**を作成してください。

# このメモの目的
- 最終ゴールは、予約フォームの「デジタル経営ビジョン①〜⑦」（＝同梱の `00_予約フォーム仕様` が定義）を埋める入力文を作ること。
- そのために電話で足りない情報を拾う。**05とHPで既に分かっていることは電話で聞かない**（重複を省くのが時短の核）。
- 聞くべきことの元ネタとルールは同梱の `07_電話ヒアリング質問シート`（汎用バンク）に従う。**質問やルールを作り替えず、07の①〜⑦の狙いに沿って、この会社向けに取捨選択・具体化**する。

# 進め方
1. **まず入力を確認する。この会社の05が渡されていなければ、会社を勝手に仮定せず「05（営業ヒアリングの回答）をください」とユーザーに確認**してから進む。会社HP（URL/本文）が無い場合は05だけで作成し、冒頭に「※HP未読。①現状把握・③選定理由・⑦強みはHP確認で精度が上がる」と明記する（会社の事実を創作しない）。
2. `00`・`07` が渡されていれば読み、予約フォームが要る情報①〜⑦と、聞ける質問・守るべきルールを把握する。無ければ本プロンプトに内蔵の①〜⑦・ルールに従う。
3. **`【この会社の05】` と `【会社HP】` を読む**。HPがURLで渡された場合はそのページ（会社概要・事業内容・サービス・拠点・沿革・強み・理念など）を読む。読めなければ貼られた本文を使う。
4. 「**05・HPで既に分かっていること**」と「**予約フォームに必要なのにまだ足りない/薄いこと**」を仕分ける。
5. 足りないことだけを、この会社向けの電話質問にして出力する。

# 守るルール（07準拠）
- **HP・05に無い事実を作らない。** HPから読み取った内容は事実として断定せず、「〜という理解で合っていますか？」と**確認する形**で質問にする（HPの記載自体も電話で裏取りする姿勢）。
- **数字は概算でOK・無ければ「未計測」で定性に**。会社固有の現状値（規模・時間・離職・年齢・使い始めまでの月数）は実数がベスト→無ければ概算→それも無ければ聞くだけ聞いて空欄可。**無い数字は作らせない**。
- **規程が定める目標数値（労働生産性+3%／給与総額+1.5%／最賃+30円、1年/3年後の目標値）は電話で聞かない**＝カラフルボックス側で付与する。②では「賃上げ・生産性向上に取り組む前提」であることの**一言共有・合意**だけ。
- **痛みは2系統**（業務効率系＝毎月◯時間・ミス・属人化／人材・組織系＝採用・離職・高齢化・制度が無い・経営層の判断負担）。**会社に合う方を主**に。両系統の入口だけ当たり、出ない系統は深掘りしない。
- **主軸は「今回のツールを入れてどうしたいか」**。コンサル等の大きな話に逸れたら戻す（賃上げ・生産性・横展開の王道目標は軽く触れてOK）。
- **NG言い換え**：「業者・営業に勧められたから」「補助金が出るから」は面談で減点。選定理由は**自社起点の決め手**（連携・価格・サポート・操作性・同業実績・機能適合等）に言い換えて1つ以上拾う。
- **⑥（経営者の関わり）は実フォームでプルダウン**。基本は「経営者が積極的にデジタル化に関わり、経営戦略として推進している」を選べる状態を目指す（`00` の⑥参照）。電話では社長の関与方針(A)社長自身が責任者／(B)担当を立て社長が最終承認、のどちらかを合意し、社長の生の一言を1フレーズ狙う。
- **相手が担当者だけ**のときは ◎必須 だけ拾えばよい。

（05の回答を貼る。「現状感じている課題」の記述があればそれを最重視。渡されていなければ生成せず、ユーザーに05を依頼する）

【会社HP】
（会社ホームページのURLを貼る＝AIが読む／読めない環境はHP本文を貼る／無ければ「なし」）

【参考：導入予定ツール・申請枠】（任意）
（分かれば。なければ「なし」）

# 出力：電話確認メモ（カンペ・A4 1枚を目安に短く）

## A. この会社について（05・HPで分かったこと＝電話で聞かない前提メモ）
- 事業内容・業種・提供サービス（HPから）／規模・拠点（分かる範囲）／現状の主なやり方・課題（05から）／導入ツールと狙い／体制の分かっている点。
- ※ここに書けたことは電話で改めて聞かない。必要なら「〜で合っていますか？」の確認だけ。

## B. 電話で確認・深掘りすること（予約フォーム①〜⑦のうち、足りない所だけ）
各項目、次の形で。**既に05・HPで十分な項目は「(05/HP取得済み)」と書いてスキップ**。
- **①現状把握**：〔優先度◎/○/△〕質問（口語）／何のため（フォームのどの欄）／メモ：＿＿＿＿
- **②将来目指す姿**：〔…〕質問／何のため／メモ：＿＿＿＿（※規程数値は聞かない・賃上げ/生産性の前提共有だけ）
- **③本申請の目的（課題→変化→選定理由）**：〔◎〕質問／何のため／メモ：＿＿＿＿（最重要。痛み2系統の入口＋自社起点の選定理由）
- **④スケジュール**：〔…〕質問／何のため／メモ：＿＿＿＿（「使い始めまで何ヶ月」を必ず／想定課題1点）
- **⑤体制整備**：〔…〕質問／何のため／メモ：＿＿＿＿（デジタル化責任者の氏名・役割／方針A/B）
- **⑥経営者の関わり**：〔◎〕質問／何のため／メモ：＿＿＿＿（社長の生の一言を1フレーズ）
- **⑦その他**：〔△〕質問／何のため／メモ：＿＿＿＿（強み・横展開。無ければ省略可）

## C. 合意しておくこと（電話で方向性の合意を取る＝後で下書きを書き直さないため）
- 課題と進め方の方向性を一度返して「だいたいこの方向で文章にして大丈夫ですか？」
- ②の「賃上げ・生産性向上に取り組む前提」の一言共有・合意
- ⑥の関与方針（A/B）の合意

## 備考（社内向け）

- 役割の住み分け：`07`＝汎用の質問バンク＋ルールの正（人が読む・質問やルールを変えるならここ）／本 `07b`＝それを **05＋HP からその会社向けに絞って生成する橋渡し**（質問・ルールは07を正として作り替えない）。`00`＝フォームが要る情報の正（変わったら00を直す・07bは追従不要）。
- このメモの狙いは電話前の準備時間の短縮。**HPを読ませて「もう分かっていること」を除外**できるほど、電話で聞くことが減り、カンペが短くなる。
- 出力メモの「メモ欄」に電話の答えを書き込めば、そのまま `06` の【電話ヒアリング回答（07）】入力になる（07bの出力→電話→06、の導線）。
- 慣れてきたら電話で臨機応変に聞けるようになる前提の「当面のカンペ」。運用の主軸は変えない。
- 機密：本プロンプトに顧客名・実数を書かない（会社固有情報は渡す05・HP側に閉じる）。
