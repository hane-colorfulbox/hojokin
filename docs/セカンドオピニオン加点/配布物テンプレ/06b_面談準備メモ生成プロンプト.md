# 面談準備メモ生成プロンプト（案件固有の想定問答の骨子）— 副・任意

カラフルボックス社内用。`06_入力整理プロンプト.md` から切り出した**任意のサブプロンプト**。
案件固有の「想定問答の答えの骨子（この会社ならこう答える）」が欲しいときだけ使う。

## いつ使うか（基本は使わない）

- 経営者に渡すのは原則 **(1) 予約フォーム入力文（=`06`の出力）＋ (2) 汎用カンペ `10`/`11`（毎回一律）** の2枚一組で足りる（2026-06-23 MTG）。
- それでも社長が汎用カンペでしっくり来ない／案件が特殊で**個社版の答えの骨子**が要る、というときだけ本プロンプトを使う。
- 出力は「練習・確認用の答えの骨子」であって、面談で棒読みするものではない。

## 二重管理しない（重要）

- **12問の問い・「確認者が見る点」・回答例の文面は `08`/`09` を正とする。本プロンプトで再定義しない。**
  - 汎用ツール案件 → `08_面談回答例_汎用中立版.md`
  - Scale人事評価の導入案件 → `09_面談回答例_スケール特化版.md`
- 本プロンプトは、その12問に対して**案件固有の事実（05/07／`06`の出力）を流し込んだ「答え（自社版）の骨子」だけ**を生成する。
- 経営者に最終的に渡す体裁は `10`/`11`（優先度ラベルなしのクリーン版）に合わせる。

## 使い方

1. 同梱物：`08`（または `09`）と、この案件の `05`/`07` の回答（または `06` で作った予約フォーム入力文）。
2. 下のプロンプトを Claude（Claude Code / Opus 推奨）に渡す。
3. 出てくる骨子は**経営者本人が自分の言葉に直す**前提で渡す。

===== プロンプトここから =====

あなたは中小企業のデジタル化・AI導入補助金（通常枠）の申請支援の専門家です。
「デジタル化セカンドオピニオン」確認者面談の練習用に、**この会社固有の「答えの骨子」**を作成してください。

# 進め方
- 同梱の `08`（汎用）または `09`（Scale案件）を読み、**12問の問い・確認者が見る点・回答例の型**を把握してください。問い・回答例の文面は **08/09 を正とし、ここでは作り替えない**でください。
- この案件の `05`/`07` の回答（または `06` で作成済みの予約フォーム入力文）を読み、各問に対する**この会社の答えの骨子**を埋めてください。

# 前提（必ず守る）
- **ヒアリング・資料に無い事実を創作しない。** 不足は「（要確認：◯◯）」と書く。数字は自社の実数のみ（無ければ作らない）。
- 答えは箇条書きの骨子で。棒読み用の長文にしない（経営者が自分の言葉で話す素材）。
- **Q8（社長自身の関わり）が最重要。** 「自分が旗を振る・方針は自分が決める・導入後も関わり続ける」を、この会社の事実に即して。
- **NG発言の警告を各所に残す**：「担当に任せている」「業者に任せているので詳しくない」「現場が決めること」「業者・営業に勧められたから」「補助金が出るから」は“他人事”に聞こえ最も評価を下げる、と注意書きを添える。
- **話の主軸は今回のツール**。コンサル導入など別の大きな話に広げない。
- **効果は投資回収まで一本で**：Q3（どう解決）・Q5（将来）の骨子は、効果（生産性向上・時間/コスト削減）で止めず「その効果でツール投資を回収し、余力を賃上げ・人材投資へ」まで定性で一言（`08`/`09` の該当箇所に沿う。既定は販管費圧縮型／売上直結ツールは売上増で回収）。数字は自社の実数のみ・無ければ作らない。
- 申請書（事業内容255字・本申請の目的）と発言を一致させる（Q11）。
- Q12は「自社の特色と熱意を自分から語るパート」。この会社の(1)なぜ始めたか(2)何を変えたいか(3)経営者としてどう関わるか、の3点を骨子で。架空の特色は作らない。

# 入力
【面談回答例（08 または 09）】
（同梱ファイルを読む。問い・確認者が見る点・回答例の型はこれを正とする）

【この案件のヒアリング回答（05＋07）／または 06 の予約フォーム入力文】
（貼る、またはファイルを読み込ませる。無い情報は「なし」）

# 出力：12問それぞれの「答え（自社版）の骨子」
- 各問について、見出し（08/09 の問い番号・問い文を引用）＋「この会社の答えの骨子（箇条書き）」＋必要なら「（要確認：◯◯）」。
- Q2〜Q5・Q7・Q8・Q11 は特に具体に（軸①②の核）。Q8 は最重要。
- 末尾に「当日チラ見用 要点カード（各1行）」：いまの一番の課題／このツールを選んだ理由／1年後の将来像／社長自身の関わり方。
- 最後に「※これは練習用の骨子です。社長ご自身の言葉に直してください。」と明記。

## 備考（社内向け）

- 役割の住み分け：`08`/`09`＝練習・模擬用（問い＋確認者視点＋回答例・優先度つき）／`10`/`11`＝経営者に渡す汎用クリーン版（毎回一律）／本 `06b`＝案件固有の答えの骨子（任意生成）。
- 出力規格（12問の問い・並び・回答例）を変えるときは **`08`/`09`/`10`/`11` 側を直す**。本プロンプトは問いを持たないので追従不要（参照先が正）。
- 機密：顧客名・実数を本プロンプトに書かない（固有名は渡す資料側＝git 管理外に閉じる）。
