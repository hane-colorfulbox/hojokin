# 外部クライアント向け 賃金台帳転記プロンプト（申請フォーマット2026「賃金台帳確認」シート用）

申請フォーマット2026の「賃金台帳確認」シートに貼り付ける一覧表を、
各社が使っている任意の AI（ChatGPT / Gemini / Claude 等）で賃金台帳から作るための指示文。

- 用途: 自動化ツール・スキルを提供していない外部企業への共有用（プロンプトのみ渡す）
- 既存の「外部クライアント向け_賃金台帳集計プロンプト.md」が合計値（給与支給総額・従業員数）を
  出すためのものだったのに対し、こちらは **シートに貼る明細行そのもの** を作らせる転記用
- 注意: AI の精度はツールによって差があるため、**出力はあくまで下書き。必ず賃金台帳の原本と
  突合してからシートに貼り付ける**こと

---

## 転記先シートの仕様（前提知識）

- 列構成: No / 氏名 / 雇用形態 / 月間平均時間 / 時給 / 月別12列 / （自動計算）給与支給総額/年・正社員換算した人数
- 月別12列の見出しは既定で「R7.1月〜R7.12月」だが、シート注記に「※決算期間に修正して使用してください」
  とあるとおり、**実際は直近事業年度の12ヶ月** を入れる（見出し側を決算期間に合わせて直す）
- 役員も行として記載し、雇用形態「役員」にする（対象外の判定・除外はシート側の数式と注記で処理）
- 支給がない月は空欄（「12ヶ月賃金の支払がない場合は対象外」とシートが判定する）
- 金額は課税支給額（入力例シートの注記「※課税支給額を入力ください」）
- 正社員換算した人数 = 月間平均時間 ÷ 160 の数式（入力例より。正社員は 160 を入れて 1.0 にする）

---

## 使い方（クライアントへの案内文）

1. お使いの AI チャット（ChatGPT / Gemini / Claude など、ファイル添付ができるもの）を開く
2. 賃金台帳のファイル（Excel または PDF）を添付する
3. 下のプロンプトをコピーして貼り付け、●●部分（決算月）だけ書き換えて送信する
4. 出てきた表を **必ず賃金台帳の原本と照合** する
5. 問題なければ、タブ区切りテキストをコピーして「賃金台帳確認」シートの B4 セル（氏名列の1行目）に貼り付ける
6. シートの月見出し（R7.1月〜R7.12月）を、AI が宣言した実際の年月に合わせて修正する

## プロンプト本文（ここからコピー）

```
あなたはデジタル化・AI導入補助金の申請書類作成を手伝う経理アシスタントです。
添付した賃金台帳から、申請フォーマットの「賃金台帳確認」シートに貼り付けるための
従業員一覧表を作成してください。

【前提】
- 当社の決算月は ●● 月です（例: 3月決算 → 3月）。
- 対象期間は「直近の事業年度の12ヶ月」です（決算月の翌月から決算月まで。
  暦年の1〜12月ではありません）。例: 3月決算なら 前年4月〜当年3月 の12ヶ月。
- 最初に「どの12ヶ月を対象にしたか」（例: 令和6年4月〜令和7年3月）を宣言してください。

【作る表の列構成】（貼り付け先のシートと同じ並び・全17列）
氏名 | 雇用形態 | 月間平均時間 | 時給 | 月別支給額（12列） | 年間通勤手当

【転記ルール】
1. 賃金台帳に載っている全員を1人1行で書いてください。役員も省かず記載し、
   雇用形態を「役員」としてください（対象/対象外の判定はシート側で行うので不要です）。
2. 月別の12列は「事業年度の最初の月」を1列目、「決算月」を12列目として、
   左から時系列順に並べてください。表の見出しに各列の年月（例: R6.4月）を明記してください。
3. 金額は各月の「課税支給合計」を使ってください。
   - 含める: 基本給、残業手当、役職手当、家族手当など課税される手当
   - 含めない: 社会保険料や税金を引いた後の「差引支給額（手取り）」
   - 通勤手当が「課税支給合計」に含まれている場合は、**そのまま含めた金額を書いて**、
     最後の「年間通勤手当」列にその年間合計を書いてください（差し引きはこちらで行います。
     そちらで引くと元の金額との検算ができなくなるためです）。
     含まれているかどうかは「基本給＋各手当＋通勤手当 ＝ 課税支給合計」が成り立つかで分かります。
   - 台帳の「課税支給合計」に通勤手当が含まれていない場合は「年間通勤手当」列は空欄です。
   - 通勤手当の金額が分からない場合（諸手当に合算されている等）は「内訳不明」と書いてください。
4. 支給がない月（入社前・退職後・休職中）は空欄のままにしてください。0 を入れてはいけません。
5. 空欄の月があっても、他の月の金額を左右に詰めてずらさないでください。
   「その月の金額は、必ずその月の列へ」を厳守してください。
6. 賞与（課税分）は、支給された月のセルに月給と合算して入れてください。
   最後に「どの人のどの月に賞与いくらを合算したか」を一覧で示してください。
7. 雇用形態は「正社員 / パート・アルバイト / 役員」のいずれかで書いてください。
   台帳から判断できない人は「要確認」としてください。
8. 月間平均時間と時給は次のとおりにしてください。
   - パート・アルバイト: 台帳の労働時間から月平均を計算して記入。時給も台帳から記入。
     読み取れない場合は「要確認」と書く。
   - 正社員: 月間平均時間に 160 を記入。時給は空欄。
   - 役員: どちらも空欄。

【出力形式】
- まず、確認用に表の形で見せてください。
- 次に、スプレッドシートに貼り付けるためのタブ区切りテキストをコードブロックで
  出してください（ヘッダー行なし。氏名から12ヶ月目まで16列。
  金額は半角数字のみで、カンマや「円」を付けない。空欄の列はタブだけ入れて飛ばす）。

【守ってほしいこと】
- 数字を推測で埋めないでください。読み取れないセルは「読み取り不可」と明記してください。
- 台帳に複数年度・複数期間が混ざっている場合は、どの12ヶ月を採用したかを必ず宣言してください。
- 台帳に合計欄があれば、転記した金額の総和と一致するか検算し、一致しない場合は
  差額と考えられる原因を書いてください。
- 最後に「人間が確認すべきポイント」（読み取りに自信がない箇所、雇用形態や賞与の扱いが
  微妙な人、支給のない月が退職か休職か不明な人など）を箇条書きでまとめてください。
```

## 渡すときの補足（社内メモ）

- 「給与支給総額/年」「正社員換算した人数」はシート側の自動計算列なので AI には作らせない
  （貼り付け範囲は氏名〜12ヶ月目の16列のみ）
- 正社員の月間平均時間 160 はシートの入力例に合わせた値（正社員換算 = 月間平均時間 ÷ 160 のため、
  160 で換算 1.0 になる）。シート側の仕様が変わったらここも直す
- 賞与をシートに入れる場所は「支給月のセルに合算」しかない（このフォーマットには賞与列がない）。
  社内ツールのテンプレ（T列に年間賞与）とはルールが違うので混同しない
- 月見出しを決算期間に直すのは人間の作業（AI 出力の宣言を見て直す）
- クライアントの AI が表をうまく読めない場合は、賃金台帳を Excel 形式でもらい直すよう案内する
